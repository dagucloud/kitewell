Kitewell 0.19.1 is a beta update for Windows. The Mac app stays on 0.19.0,
which already reads PDFs with PDFKit.

## What's in this release

- A Windows PC now reads PDFs without extra software. **Teach from a
  manual** and a hand-over file used to need poppler's pdftotext on
  Windows, which most PCs do not have, so Kitewell asked for Word or text
  instead, after the file had been uploaded. The Windows app now carries
  PDFium, Chrome's PDF engine, and reads a PDF with it when pdftotext is not
  installed, including the fonts Japanese PDFs embed; a 97-page Japanese
  manual reads in about two seconds. Where pdftotext is installed it is
  still used, for the layout of tables.

## Upgrading

Nothing to do. Kitewell 0.18.4 updates itself to 0.19.1 at a quiet moment,
and running workflows go on across the restart.
