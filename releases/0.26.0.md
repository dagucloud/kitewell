Kitewell 0.26.0 is a beta update.

## What's in this release

- Each workflow keeps its own time zone. A new one takes yours, its
  schedules fire on that zone's clock (daylight saving included), and its
  steps run in it. Times show on your own clock, and where a workflow keeps
  another zone, both are shown.
- What Kitewell builds or changes for you applies at once and shows as done,
  with **Undo** beside it. The assistant says what it did rather than what
  it proposes.
- Home is a plain page with one first action, and setup offers a
  one-minute example again, in English and Japanese.
- Signing in to Kitewell Cloud opens Kitewell's own sign-in page at
  app.kitewell.com, with Google or email. **Open Kitewell Cloud** opens
  app.kitewell.com.
- Kitewell answers in the language you chose from the first screen:
  notifications, the menu bar, error messages, and how long things took,
  such as 2分45秒.
- A finished run says what it did in plain words, such as "invoices.xlsx
  (Invoices): 3 rows added". The values it published are one click away.
- A call the assistant corrects by itself no longer shows as an error.
- Desktop steps read the screen with the project's screen model, and
  letting AI fix a desktop step uses it too.
- CSV files are read and written in the encodings Excel uses, and a run on a
  Mac warns before it writes a workbook that is open in Excel.
- Kitewell Team runs on a computer that never reaches the internet, with a
  license key from the account page.
- Kitewell bundles Dagu 2.26.0.

## Upgrading

Nothing to do. Kitewell 0.25.3 updates itself to 0.26.0 at a quiet moment,
and running workflows go on across the restart. Schedules saved before this
release keep the zone they were saved in.
