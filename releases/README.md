# Public release notes

Only published releases have a numeric `0.x.y.md` file here. The website renders
those files on /releases/. Draft release notes belong in the private source
repository and are copied here by its publisher after download verification.

Include changes, known issues, system requirements, and any upgrade actions.
Installers, checksums, and corresponding third-party source are GitHub Release
assets, not Git files. Public release tags reference this repository's history.
