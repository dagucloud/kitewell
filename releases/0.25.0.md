Kitewell 0.25.0 is a beta update.

## What's in this release

- A new computer opens on a three-step setup in place of an empty project
  list: sign in, allow the computer's access, then describe a first chore or
  pick a ready request, which is sent at once.
- On a Mac, Screen Recording and Accessibility are allowed from one panel.
  Each has an **Allow** button that opens the right pane of System Settings,
  and the panel turns to Allowed by itself. Kitewell shows the panel before
  it builds an automation that needs them, and sends the request once both
  are allowed.
- An empty project asks for the chore in your own words, and the overview
  lists what a new computer still has to do: describe a first automation,
  try it once, put it on a schedule. A proposed workflow is saved with
  **Save it** and then offers **Try it now**.
- The sidebar leads with the pages used every day. MCP, Queues, Secrets,
  and Diagnostics wait under one **Advanced** group.
- On Windows, starting at sign-in is a switch in setup, no longer set at
  launch. The first time the window is closed, Kitewell says it stays in the
  tray.
- The spotlight tour no longer starts by itself in the desktop app.
- A Kitehand hand no longer asks about what a page sends another company by
  itself, such as an advertising or measuring beacon. It asks before a save
  on the site it is working on, or a form that page submits, and names that
  site. The page's other requests stay held back and no longer stop the
  hand.
- A hand no longer writes a page of its notes for each piece of work it
  builds or changes, and no longer asks you to approve a note. It keeps
  notes when it is set up, when you ask it to, and when a page is wrong.
- A hand fixes and saves its own work without asking whether it may.
- A public page of a ready-made hand says what the hand does and lists the
  other ready-made hands in its language. It no longer shows stars, counts,
  a ranking, or an author.

## Removed

- Choosing per workflow which events reach the connected AI, the cases
  those events opened, the weekly case, and an AI's repair held apart for a
  trial, all added in 0.24.0, are gone. ChatGPT and Claude still read, run,
  and change workflows over MCP, and MCP Events are delivered as before.

## Upgrading

Nothing to do. Kitewell 0.24.0 updates itself to 0.25.0 at a quiet moment,
and running workflows go on across the restart.
