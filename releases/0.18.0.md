Kitewell 0.18.0 is the first public beta for Windows.

Kitewell runs workflows on your own computer: scheduled commands, Docker
containers, coding agents and API models, browser and desktop steps, email,
HTTP, SSH, and imported APIs, edited as a graph or as YAML. Each project runs
on a bundled Dagu engine, kept running after the window closes, and Kitewell
can connect to Dagu Cloud for sync, remote MCP, and run status.

## What's in this release

- The bundled engine is Dagu 2.21.0.
- Installing is one download and one click: `Kitewell-0.18.0-win-x64-Setup.exe`
  installs Kitewell for the current user, with no wizard and no administrator
  prompt, and opens it. WebView2 is installed on first launch when the PC
  lacks it.
- Updates arrive by themselves: Kitewell downloads a new version in the
  background, checks it against the Kitewell release key, and installs it at
  the next launch or at a quiet moment. Running workflows go on across the
  restart.

## Requirements

- Windows 10 or Windows 11, x64. ARM PCs run the x64 build under emulation.
- About 1 GB of free disk space for the app and its updates.

## Known issues

- Only x64 is shipped; a native ARM build does not exist yet.
- The Mac release of 0.18.0 follows separately.

## Upgrading

Nothing to do. Kitewell 0.18.0 is the first public release; earlier builds
were private test builds and are not updated from.
