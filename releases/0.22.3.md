Kitewell 0.22.3 is a beta update.

## What's in this release

- The project picker no longer says a project is starting long after it
  started. It read the other projects' states only when the window opened,
  so after an update restarted them they kept saying **Starting…**. The
  menu now reads them each time it opens.
- The picker marks only projects that do not run: **Paused**, or **Not in
  plan**. A running project, and one starting or stopping, has no label.
- The box that narrows a long project list is lighter.

## Upgrading

Nothing to do. Kitewell 0.22.2 and 0.22.1 update themselves to 0.22.3 at a
quiet moment, and running workflows go on across the restart.
