Kitewell 0.22.2 is a beta update.

## What's in this release

- The project picker says in words how each project stands: **Paused**,
  **Starting…**, **Needs attention**, or **Not in plan**, with nothing beside
  a project that is running. It used to mark them with circles that some
  fonts drew as specks, so a project starting looked like a stray dot.
- The picker works from the keyboard as a menu does: arrow keys, Home, End,
  Enter, Escape, and a letter to jump to a project. With six or more
  projects, a box at the top narrows the list as you type. A project that
  starts or pauses while the menu is open no longer closes it.
- **Manage projects** is at the foot of the picker's menu, in place of the
  small link below it.

## Upgrading

Nothing to do. Kitewell 0.22.1 and 0.21.0 update themselves to 0.22.2 at a
quiet moment, and running workflows go on across the restart.
