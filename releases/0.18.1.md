Kitewell 0.18.1 is the first public beta for macOS.

Kitewell runs workflows on your own computer: scheduled commands, Docker
containers, coding agents and API models, browser and desktop steps, email,
HTTP, SSH, and imported APIs, edited as a graph or as YAML. Each project runs
on a bundled Dagu engine, kept running after the window closes, and Kitewell
can connect to Dagu Cloud for sync, remote MCP, and run status.

## What's in this release

- The bundled engine is Dagu 2.21.0.
- One installer for each kind of Mac: `Kitewell-0.18.1-arm64.pkg` for a Mac
  with an Apple chip, and `Kitewell-0.18.1-amd64.pkg` for one with an Intel
  processor. Both are signed and notarized by Apple. The installer puts
  Kitewell in Applications and asks for an administrator password.
- Updates arrive by themselves: Kitewell downloads a new version in the
  background, checks it against the Kitewell update key, and installs it at
  a quiet moment or when you choose **Restart to Update** in the Kitewell
  menu. Running workflows go on across the restart.

## Requirements

- macOS 13 Ventura or later, on an Apple chip or an Intel processor.
- About 3 GB of free disk space for the app and its updates.

## Known issues

- This release has Mac installers only. Windows is on Kitewell 0.18.0.

## Upgrading

Nothing to do. Kitewell 0.18.1 is the first public release for macOS; earlier
Mac builds were private test builds and are not updated from.
