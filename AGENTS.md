# Kitewell public repository

- Website, customer documentation, and release materials only. Application source stays private.
- Work in this checkout. Commit and push incremental changes on main.
- Keep installers in GitHub Releases, never Git history.
- Keep the preview honest: download buttons come only from a valid published manifest.
- Keep product branding platform-neutral. Use OS names for availability and platform-specific instructions.
- Run website checks, tests, and build before pushing.
- Keep the Ink identity: white paper, near-black ink, and the kite green only for the mark and primary actions, all from `website/src/styles/tokens.css`. The play colors there are for idea cards and highlights only, never for controls or text. No gradients, glows, decorative icons, or status dots. Use system fonts and accessible HTML.
- Talk to visitors as collaborators, not prospects: lead with what they could make and invite them in. Team and company detail lives on /teams/.
- Never commit credentials, private customer data, or unpublished legal drafts.
