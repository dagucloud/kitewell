Descarty株式会社（以下「当社」）は、Kitewell を提供しています。本ポリシーは、Kitewell のアプリと kitewell.app のウェブサイトが扱う情報、その送り先、当社が受け取る情報について説明します。

要点：Kitewell はお使いの端末で動きます。ワークフロー、実行履歴、ログ、認証情報、接続したメールボックスは端末に残り、当社は受け取りません。

## 1. 端末に残るデータ

Kitewell は、ワークフローの定義、実行の記録、ログ、出力ファイル、設定、バックアップを、Kitewell を動かす端末に保存します。保存したシークレットは端末上で暗号化されます。当社はこれらのデータを受け取らず、Kitewell が当社に送ることもありません。

ワークフローは、Kitewell を動かすアカウントがアクセスできるファイルを読み書きできます。実行の出力には個人情報や認証情報が含まれることがあります。ログを共有する前に内容を確認してください。バックアップとプロジェクトのエクスポートは暗号化されません。取り扱いにご注意ください。アプリを削除しても、ワークスペース、バックアップ、認証情報は残ります。削除の方法はアンインストールのガイドで説明しています。

## 2. お客様が選ぶ接続先

ワークフローは、お客様が設定した接続先にデータを送ります。AI の提供者、API、コマンドラインのエージェント、コンテナ、SSH サーバー、メールサーバー、Slack、Microsoft Teams などです。プロンプト、文脈、ファイル、出力は、ワークフローの定めに従ってこれらの接続先に送られます。送られたデータは、各接続先の規約とプライバシーポリシーに従って扱われます。

## 3. 接続したメールボックス（Gmail、Microsoft 365、IMAP）

メールボックスを接続すると、ワークフローでメールを探し、読み、整理し、送信できます。この項では、Google API を通じて受け取るデータを含め、メールボックスから受け取るデータの扱いを説明します。

**求める権限**　Google アカウントを接続するとき、Kitewell は Google に、メールアドレス（`openid`、`email`）と Gmail へのアクセス（`https://mail.google.com/`）を求めます。Kitewell は IMAP と SMTP でメールを読み書きしており、Google はこれらに対してより狭い権限を用意していないためです。Microsoft のサインインでは、同等の IMAP と SMTP の権限を求めます。そのほかのメールボックスは、アプリパスワードで接続します。

**使い道**　メールアドレスは、サインインしたアカウントが入力されたメールボックスと同じかを確かめるために使います。メールへのアクセスは、お客様が Kitewell で指示したことにだけ使います。接続の確認、フォルダの一覧、そしてワークフローのメールのステップ（そのメールボックスのメールを探す、読む、既読にする、移動する、送信する）です。

**保存場所**　アクセストークンは、端末上に暗号化したプロジェクトのシークレットとして保存します。ワークフローが読んだメールは、実行の出力とログとして端末に保存され、実行の保存期間に従います。トークンが、ワークフローのファイル、ログ、バックアップ、エクスポート、Dagu Cloud に入ることはありません。

**送り先**　メールの内容が端末の外に出るのは、お客様のワークフローが送る場合だけです。たとえば、お客様が選んだ AI の提供者やメールの宛先です。当社は、お客様のメールや Google アカウントのデータを受け取らず、保存せず、アクセスもしません。

**行わないこと**　Kitewell は、メールボックスのデータを広告に使わず、販売せず、AI や機械学習のモデルの開発、改善、学習に使いません。当社の者がメールを読むこともありません。

**Limited Use**　Kitewell's use and transfer of information received from Google APIs to any other app will adhere to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.（Google API から受け取った情報の Kitewell による利用と他のアプリへの転送は、Limited Use の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。）

**接続の解除**　Kitewell でメールボックスの接続を解除すると、端末からトークンを削除し、Google アカウントへの Kitewell のアクセスを取り消します。[Google アカウントの権限のページ](https://myaccount.google.com/permissions)からも、いつでもアクセスを削除できます。Microsoft の場合は、アカウントのアプリの権限から削除できます。

## 4. Dagu Cloud のアカウントとプロジェクトの同期

Kitewell はアカウントなしで使えます。アカウントがなければ、Kitewell が Dagu Cloud に接続することはありません。

Dagu Cloud でサインインすると、端末はプランを確認し、Kitewell のバージョンを送ります。ワークフロー、設定、実行履歴、ログ、シークレットは送りません。Kitewell は、アカウントの識別子、メールアドレス、ライセンス、端末の接続用の認証情報を端末に保存します。

プロジェクトの同期を選ぶと、Kitewell はそのプロジェクトの定義を Dagu Cloud に送ります。ワークフローとスケジュール、エージェントとモデル、API の接続、サーバー、キュー、シークレットの名前と説明、保存した一括処理の入力、プロジェクトの既定値です。シークレットの値は送りません。ワークフローの YAML、一括処理の入力、API のアドレスに直接書いた文字列は、そのまま送られます。

アカウント、サブスクリプション、支払い、チームへの招待、同期したプロジェクトは、Dagu Cloud が [Dagu のプライバシーポリシー](https://dagu.sh/privacy)に従って扱います。

## 5. アップデートとダウンロード

アップデートの確認のため、Kitewell は kitewell.app から公開のバージョン一覧を取得します。インストーラーは GitHub Releases から、エンジンのアップデートはその配布元からダウンロードします。一般的なウェブのリクエストと同じく、受け取るサービスには IP アドレスが伝わります。ワークフローのデータは含みません。

## 6. kitewell.app のウェブサイト

ウェブサイトは Cloudflare Pages で公開しています。訪問数を把握するため、PostHog を利用しています。PostHog は、閲覧したページ、参照元のサイト、端末とブラウザの種類を記録し、そのための識別子をブラウザに保存します。画面の録画やキー入力の記録は行いません。Cloudflare は、セキュリティと運用のためにリクエストのログを保存することがあります。

## 7. サポート

GitHub の公開の Issue は誰でも閲覧できます。シークレットや非公開のワークフローのデータを含めないでください。GitHub の非公開の報告機能で送られたセキュリティの報告と、当社へのメールは、Kitewell の担当者だけが確認します。

## 8. 当社が受け取る情報の利用目的

当社が受け取る情報（ウェブサイトの訪問の統計と、お客様から届いたメッセージ）は、Kitewell とウェブサイトの運営と改善、お問い合わせへの回答、セキュリティの報告への対応に使います。当社は個人情報を販売せず、お客様の同意がある場合または法令に基づく場合を除き、第三者に提供しません。

## 9. 外国にある事業者の利用

PostHog, Inc.、Cloudflare, Inc.、GitHub, Inc. はアメリカ合衆国の事業者で、同国のサーバーで情報を処理します。アメリカ合衆国の個人情報の保護に関する制度については、[個人情報保護委員会のウェブサイト](https://www.ppc.go.jp/)で公表されている情報をご参照ください。
