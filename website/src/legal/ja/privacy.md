Descarty株式会社（以下「当社」）は、Kitewell を提供しています。本ポリシーは、Kitewell のアプリと kitewell.app のウェブサイトが扱う情報、その送り先、当社が受け取る情報について説明します。

要点：Kitewell はお使いの端末で動きます。ワークフロー、実行履歴、ログ、認証情報、接続したメールボックスは端末に残り、当社は受け取りません。ChatGPT や Claude を接続した場合、それらが Kitewell のツールで読む内容は当社のリレーを通過しますが、保存されません。Webhook をオンにした場合、ほかのサービスが送ったリクエストは、端末が受け取るまで最大 7 日間、当社のリレーで待ちます。

## 1. 端末に残るデータ

Kitewell は、ワークフローの定義、実行の記録、ログ、出力ファイル、設定、バックアップを、Kitewell を動かす端末に保存します。保存したシークレットは端末上で暗号化されます。当社はこれらのデータを受け取らず、Kitewell が当社に送ることもありません。接続した AI アプリがこれらのデータにアクセスするのは、第 5 項で説明する方法に限られます。

ワークフローは、Kitewell を動かすアカウントがアクセスできるファイルを読み書きできます。実行の出力には個人情報や認証情報が含まれることがあります。ログを共有する前に内容を確認してください。バックアップとプロジェクトのエクスポートは暗号化されません。取り扱いにご注意ください。アプリを削除しても、ワークスペース、バックアップ、認証情報は残ります。削除の方法はアンインストールのガイドで説明しています。

## 2. お客様が選ぶ接続先

ワークフローは、お客様が設定した接続先にデータを送ります。AI の提供者、API、コマンドラインのエージェント、コンテナ、SSH サーバー、メールサーバー、Slack、Microsoft Teams などです。プロンプト、文脈、ファイル、出力は、ワークフローの定めに従ってこれらの接続先に送られます。送られたデータは、各接続先の規約とプライバシーポリシーに従って扱われます。

## 3. 接続したメールボックス（Gmail、Microsoft 365、IMAP）

メールボックスを接続すると、ワークフローでメールを探し、読み、整理し、送信できます。この項では、Google API を通じて受け取るデータを含め、メールボックスから受け取るデータの扱いを説明します。

**求める権限**　Google アカウントを接続するとき、Kitewell は Google に、メールアドレス（`openid`、`email`）と、Gmail のメールを読み、整理し、送信する権限（`https://www.googleapis.com/auth/gmail.modify`）を求めます。Kitewell は Gmail API を通じて Gmail にアクセスします。この権限では、メールの読み取り、既読・未読などのラベルの変更、ゴミ箱への移動、メールの送信ができますが、メールを完全に削除することはできません。Microsoft のサインインでは、IMAP と SMTP でメールを読み書きする権限を求めます。そのほかのメールボックスは、アプリパスワードで接続します。

**使い道**　メールアドレスは、サインインしたアカウントが入力されたメールボックスと同じかを確かめるために使います。メールへのアクセスは、お客様が Kitewell で指示したことにだけ使います。接続の確認、フォルダの一覧、そしてワークフローのメールのステップ（そのメールボックスのメールを探す、読む、既読にする、移動する、送信する）です。

**保存場所**　サインインのトークン、または入力されたアプリパスワードは、端末上の 2 か所だけに保存します。Kitewell のメールボックスのファイルと、ワークフローエンジンのシークレットストアです。どちらも暗号化します（後述の「保護の方法」を参照）。ワークフローが読んだメールは、実行の出力とログとして端末に保存され、実行の保存期間に従います。トークンが、ワークフローのファイル、ログ、バックアップ、エクスポート、Dagu Cloud に入ることはありません。

**受け取る者**　当社は、Google ユーザーデータを含むメールボックスのデータを、販売、共有、転送、開示しません。保存のために当社に送られることはなく、当社の者が読むこともできません。データが端末の外に出るのは、次の場合だけです。いずれもお客様の指示によります。

- **ワークフローの送り先**　お客様が作るワークフローのステップは、メールの内容を、お客様が選んだ送り先に送ることができます。たとえば AI の提供者（OpenAI や Anthropic など）、API、メールの宛先です。送られたデータは、各送り先の規約とプライバシーポリシーに従って扱われます。
- **接続した AI アプリ（第 5 項）**　リモートアクセスを有効にして ChatGPT や Claude を接続すると、そのアプリは実行の出力を読めます。出力には、ワークフローが読んだメールが含まれることがあります。データは暗号化されて mcp.kitewell.app の Kitewell のリレーを通り、OpenAI または Anthropic に届きます。リレーは Cloudflare 上で動き、データを保存しません。
- **MCP イベント（第 5 項）**　人の対応を待つステップのイベントには、その質問や作業の文面が含まれ、メールを引用していることがあります。イベントは、購読したアプリが指定した HTTPS のアドレスに送られます。

当社はメールボックスのデータを保有しないため、法的な要請を含め、開示できるデータはありません。

**保護の方法**

- **通信の暗号化**　Kitewell は、Gmail には Gmail API を通じて HTTPS で、Microsoft やそのほかのメールサーバーには TLS または STARTTLS で接続します。リレーとの通信も HTTPS です。
- **保存時の暗号化**　サインインのトークンとアプリパスワードは AES-256-GCM で暗号化します。鍵は端末の外に出ず、トークンと鍵を保存するファイルは、端末のお客様のユーザーアカウントだけが読めます。実行の出力とログにあるメールも、同じファイルの権限で保護されます。これらも保存時に暗号化するには、FileVault や BitLocker などの OS のディスク暗号化を有効にしてください。
- **サインイン**　Google や Microsoft へのサインインはお客様のブラウザで行うため、Kitewell がアカウントのパスワードを見ることはありません。サインインには PKCE と 1 回限りの state 値を使う OAuth 2.0 を用い、端末のループバックアドレスで待つ Kitewell にだけ戻ります。
- **アクセスの制限**　リモートアクセスは、お客様が有効にするまで無効です。接続する AI アプリにはお客様の承認が必要で、いつでも取り消せます。ローカルの MCP や REST のクライアントには、お客様が選んだプロジェクトに限った API キーが必要です。
- **出力での秘匿**　ワークフローエンジンは、ログと実行の出力に現れるトークンやパスワードを伏せ字にします。
- **削除**　メールボックスの接続を解除すると、端末からトークンを削除します（後述の「接続の解除」を参照）。

**行わないこと**　Kitewell は、メールボックスのデータを広告に使わず、販売せず、AI や機械学習のモデルの開発、改善、学習に使いません。当社の者がメールを読むこともありません。

**Limited Use**　Kitewell's use and transfer of information received from Google APIs to any other app will adhere to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.（Google API から受け取った情報の Kitewell による利用と他のアプリへの転送は、Limited Use の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。）

**接続の解除**　Kitewell でメールボックスの接続を解除すると、端末からトークンを削除します。同じ端末のほかのプロジェクトがそのメールボックスを使っていなければ、Google アカウントへの Kitewell のアクセスも取り消します。取り消すと、そのアカウントの Kitewell のアクセスはすべての端末で終わります。[Google アカウントの権限のページ](https://myaccount.google.com/permissions)からも、いつでもアクセスを削除できます。Microsoft の場合は、アカウントのアプリの権限から削除できます。

## 4. Dagu Cloud のアカウントとプロジェクトの同期

Kitewell はアカウントなしで使えます。アカウントがなければ、Kitewell が Dagu Cloud に接続することはありません。

Dagu Cloud でサインインすると、端末はプランを確認し、Kitewell のバージョン、端末の ID と名前を送ります。ワークフロー、設定、実行履歴、ログ、シークレットは送りません。Kitewell は、アカウントの識別子、メールアドレス、ライセンス、端末の接続用の認証情報を端末に保存します。

プロジェクトの同期を選ぶと、Kitewell はそのプロジェクトの定義を Dagu Cloud に送ります。ワークフローとスケジュール、エージェントとモデル、API の接続、サーバー、キュー、シークレットの名前と説明、保存した一括処理の入力、プロジェクトの既定値です。シークレットの値は送りません。ワークフローの YAML、一括処理の入力、API のアドレスに直接書いた文字列は、そのまま送られます。

アカウント、サブスクリプション、支払い、チームへの招待、同期したプロジェクトは、Dagu Cloud が [Dagu のプライバシーポリシー](https://dagu.sh/privacy)に従って扱います。

## 5. AI アプリの接続（リモート MCP）

ChatGPT や Claude を、`https://mcp.kitewell.app/mcp` を通じてお使いの端末の Kitewell に接続できます。Dagu Cloud のアカウントが必要で、Kitewell でリモートアクセスをオンにするまでは使われません。

**リレーを通過するもの**　AI アプリから端末へのリクエストと端末の応答は、Kitewell のリレー（mcp.kitewell.app で動く Cloudflare Worker）を通過します。通過するだけで、次に説明する探索の応答を除き、その内容が保存されることはありません。

**リレーが保存するもの**　リレーが端末ごとに保存するのは、端末の名前、Kitewell のバージョン、最後に接続を確認した時刻、探索の呼び出し（`server/discover`、`initialize`、`tools/list`、`resources/list`、`resources/templates/list`）への直近の応答だけです。これにより、端末がオフラインの間もコネクタが使える状態に保たれます。これらは、端末との最後の通信から 30 日後にすべて削除されます。

**Dagu Cloud が保存するもの**　アプリを接続するには Dagu Cloud にサインインします。Dagu Cloud は、接続ごとに次の情報を保存します。

- アプリの登録情報：名前とリダイレクト URI
- 許可の情報：ユーザーとワークスペース、端末の ID と名前、アプリの名前とリダイレクト先のホスト、権限、プロジェクトの ID、日時、リフレッシュトークンの状態

端末は、サインインしている間、その ID と名前を Dagu Cloud に送ります（第 4 項）。許可は、取り消されたとき、またはリフレッシュトークンが 90 日間使われなかったときに終了し、終了から 7 日後に削除されます。完了しなかった許可は、認可コードの期限が切れた 1 日後に削除されます。登録済みのアプリは、許可が残っておらず 180 日間使われなかったときに削除されます。

**端末に残るもの**　Kitewell は、接続済みのアプリの一覧と、それぞれを最後に使った日時を端末に保存します。

**MCP Events**　アプリがイベントを購読すると、端末は各イベントを、そのアプリが指定した HTTPS のアドレスに、アプリのシークレットで署名して直接送ります。イベントには、プロジェクト、ワークフロー、実行の ID、ステータス、日時、失敗したステップの名前、人の対応を待つステップについてはその質問やタスクの文章が含まれます。購読とそのシークレットは端末に残ります。

**AI の提供者**　OpenAI（ChatGPT）または Anthropic（Claude）は、接続したアプリが Kitewell のツールで読む内容を受け取り、各社の規約とプライバシーポリシーに従って扱います。

**接続の停止**　Kitewell でリモートアクセスをオフにするか、**接続済みのアプリ** でアプリを失効させると、そのアプリのアクセスは止まります。

## 6. Webhook

ワークフローに `https://hooks.kitewell.app` の Webhook の URL を設定し、お客様が選んだサービスからのリクエストでワークフローを開始できます。Dagu Cloud のアカウントと Kitewell Personal または Team が必要で、ワークフローごとにオンにするまでは使われません。

**リレーが保存するもの**　各リクエストは、本文とヘッダーとともに、第 5 項で説明した Cloudflare Worker である Kitewell のリレーに届きます。Cookie、`Authorization`、Cloudflare が追加するヘッダーは取り除かれます。リレーは、端末が受け取るまでリクエストを保存し、受け取られた時点で削除します。端末が 7 日以内に受け取らなかったリクエストも削除します。Webhook ごとに保存するのは、URL の秘密の部分のハッシュだけです。端末のほかのデータと同じく、端末との最後の通信から 30 日後にすべて削除されます。

**端末に残るもの**　リクエストの本文とヘッダーは、開始した実行の入力となり、実行履歴とともに、お客様が設定した保持期間だけ残ります。Kitewell は、ワークフローごとに最新 20 件のリクエストについて、届いた日時、サイズ、結果も保存します。

**送り手**　リクエストに何を含めるかは、送り手のサービスが、各社の規約とプライバシーポリシーに従って決めます。GitHub の Issue や Stripe の支払いに含まれる氏名やメールアドレスなど、個人情報が含まれることがあります。

**停止**　ワークフローの Webhook をオフにすると、端末がリレーに伝え、リレーはその URL を拒否して、待っているリクエストを削除します。新しい URL にしたときも、同じように古い URL が置き換わります。

## 7. アップデートとダウンロード

アップデートの確認のため、Kitewell は kitewell.app から公開のバージョン一覧を取得します。アプリが起動している間はおよそ 1 日に 1 回、また **Check for Updates…** を選んだときに取得します。インストーラーは GitHub Releases から、エンジンのアップデートはその配布元からダウンロードします。一般的なウェブのリクエストと同じく、受け取るサービスには IP アドレスが伝わります。ワークフローのデータは含みません。

## 8. kitewell.app のウェブサイト

ウェブサイトは Cloudflare Pages で公開しています。訪問数を把握するため、PostHog を利用しています。PostHog は、閲覧したページ、参照元のサイト、端末とブラウザの種類を記録し、そのための識別子をブラウザに保存します。画面の録画やキー入力の記録は行いません。Cloudflare は、セキュリティと運用のためにリクエストのログを保存することがあります。

## 9. サポート

GitHub の公開の Issue は誰でも閲覧できます。シークレットや非公開のワークフローのデータを含めないでください。GitHub の非公開の報告機能で送られたセキュリティの報告と、当社へのメールは、Kitewell の担当者だけが確認します。

## 10. 当社が受け取る情報の利用目的

当社が受け取る情報（ウェブサイトの訪問の統計と、お客様から届いたメッセージ）は、Kitewell とウェブサイトの運営と改善、お問い合わせへの回答、セキュリティの報告への対応に使います。リレーが保存する情報（第 5 項と第 6 項）は、コネクタの運用と Webhook の配送に使います。当社は個人情報を販売せず、お客様の同意がある場合または法令に基づく場合を除き、第三者に提供しません。
