title: Dagu Console
---

在 [console.dagu.sh](https://console.dagu.sh) 上，Dagu Console 可以在任何浏览器中（包括手机浏览器）显示已同步项目的运行情况。工作仍由你的电脑完成。控制台只接收每次运行的状态，从不接收其日志、输出或密钥的值。

## 准备工作

- 一个 Dagu Cloud 账户和一个[已同步的项目](/zh/docs/cloud-sync/)。所有套餐均可使用，包括免费套餐。未同步的项目从不报告。
- 如需查看多台电脑，需要 Kitewell Team。免费账户和 Kitewell Personal 各只能容纳一台电脑。

使用你的电脑所用的账户登录 Dagu Console。工作区所有者可以看到每个已同步的项目和每台电脑。工作区中的其他人可以看到自己拥有角色的项目的运行、自己的电脑，以及运行过这些项目的电脑。

## 查看运行

**监控** 下的各个页面同时涵盖 Kitewell 电脑和 Dagu 服务器：

- **概览**：正在报告的电脑数量、今天的失败、未解决的告警，以及需要关注的电脑。
- **电脑**：每台电脑的 **状态**（**报告中** 或 **报告中断**）、用户、Kitewell 版本、操作系统、最后一次报告，以及进行中的运行和今天失败的运行。选择一台电脑可查看它最近 14 天的运行。
- **运行**：所有运行，可按项目、工作流、状态和时间查看。
- **洞察**：每个工作流在 7 天、30 天或 90 天内的运行次数、失败次数、成功率和耗时。

![Dagu Console 的电脑页面，两台 Kitewell 电脑正在报告，显示了用户、Kitewell 版本、操作系统和最后一次报告](../../../../assets/docs/zh/console-computers.png)

电脑每两分钟报告一次，进行中的运行有变化时会更早。页面显示的是打开时已收到的内容；选择 **刷新** 可查看最新情况。

## Dagu Console 的告警

在所有套餐上，Dagu Console 都会发出两类告警：

- 工作流失败。无论有多少台电脑运行同一个工作流，它都只有一条告警。之后任何一台电脑上的失败都会计入这条告警，任何一台电脑上的下一次成功会将其解除。已中止和已拒绝的运行会被计数，但不会触发告警。
- 电脑停止报告。10 分钟没有收到报告时会发出告警，电脑重新报告后解除。此告警默认关闭，因为电脑每次进入睡眠都会停止报告。

如需监视一台应保持开机的电脑，工作区所有者可在 **电脑** 下打开它，勾选 **此电脑停止报告时发出告警**，然后选择 **保存更改**。

![Dagu Console 中一台电脑的页面，显示了详情、最近的运行，以及“此电脑停止报告时发出告警”选项](../../../../assets/docs/zh/console-computer.png)

告警发出时和解除时都会发送邮件：

- 电脑停止报告时，会发邮件给工作区所有者。
- 工作流失败的邮件需由所有者开启：在 **设置** 的 **告警邮件** 下，在 **所有者和管理员** 一行勾选 **Kitewell**，然后选择 **保存更改**。邮件会发给所有者和该项目的管理员。
- **添加收件人** 可以添加勾选了 **Kitewell** 的 **成员** 或 **外部地址**。两者都会收到电脑停止报告和工作流失败的通知：成员收到自己能打开的项目和能看到的电脑的通知，外部地址在验证后收到所有项目的通知。

### Kitewell 的提醒与 Dagu Console 的告警

[Kitewell 自身的提醒](/zh/docs/alerts/)来自电脑。两者可以并行使用：

| | Kitewell 的提醒 | Dagu Console 的告警 |
| --- | --- | --- |
| 发送方 | 电脑 | Dagu Cloud |
| 套餐 | Personal 和 Team | 所有套餐 |
| 事件 | 失败、恢复、需要输入、错过计划、运行时间过长、被取消、成功、完成批次 | 工作流失败；电脑停止报告 |
| 渠道 | 此设备、电子邮件、Slack、Microsoft Teams、PagerDuty、Webhook | 电子邮件 |
| 电脑睡眠期间 | 不发送任何内容；错过的计划会在唤醒后报告 | 发出停止报告告警 |

<a id="what-dagu-console-keeps"></a>

## Dagu Console 保存的内容

- 每次运行的工作流、状态、触发方式、时间和失败步骤的名称，保存 14 天。一个工作区每天（UTC）最多保存 500 次已结束的运行；超过后，**设备设置** 会显示运行历史何时恢复记录。
- 每个工作流的每日汇总，用于洞察，保存 13 个月。
- 告警，在解除后保存 90 天。
- 30 天没有报告的电脑会被移除，连同它报告过的所有内容。

如需停止发送运行状态，由工作区所有者按[在 Dagu Cloud 中查看运行](/zh/docs/cloud-sync/#follow-runs-in-dagu-cloud)中所述将其关闭。之后电脑只报告自己正在运行。
