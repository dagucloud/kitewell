title: Kitewell Cloud
---

Kitewell Cloud 是在浏览器中使用的 Kitewell，无需安装。你在这里创建的每个项目都有自己的云端机器，所以电脑合上时也会按计划运行。可在浏览器或手机上创建和修改工作流。

## 开始

1. 打开 [app.kitewell.com](https://app.kitewell.com/)，登录 Dagu Cloud；如果还没有账号，就创建一个。
2. 选择 **创建项目** 并为它命名。Kitewell 会为项目准备机器，大约需要 20 秒。
3. 像[你的第一个工作流](/zh/docs/getting-started/)那样，告诉助手要做的工作。

创建第一个项目即开始 14 天免费试用，无需信用卡。试用期间只能有 1 个项目。如需更多，请订阅 Kitewell Personal 或 Team。

## 云端运行分钟数

Kitewell Cloud 与套餐分开计费，按运行所用的分钟数计算。每次运行向上取整到整分钟。等待人工批准以及与助手一起构建的时间不计。

- 每个工作区无论使用哪个套餐，每月都有 1,000 分钟免费。
- 超出部分每分钟 0.007 美元（日本为 1 日元，不含税）。工作区所有者在账户页面添加银行卡并设置每月预算后，按预算上限计费。
- 未设置预算时，免费分钟用完后，Kitewell Cloud 在下个月之前不会开始新的运行，应用中会有提示。不会收费。
- 在此期间，你仍可打开项目、查看过去的运行并导出。
- 在你自己的电脑上运行永不计量。

## 团队协作

在 Kitewell Team（包括试用期）中，工作区所有者可以在浏览器中邀请成员：

1. 选择你姓名旁的齿轮图标，打开 **账户**。在 **团队** 中输入对方的邮箱地址，然后选择 **邀请**。Kitewell 会通过邮件把链接发给对方，并向你显示一次链接，方便你也发给对方。
2. 对方打开链接，用该地址登录或注册，然后选择加入。Kitewell 会为对方打开你的工作区。
3. 在 **同步项目** 中，为对方参与的每个项目设置 **编辑者** 或 **管理员**，然后选择 **保存访问权限**。打开云端项目需要其中之一。

每个人也都保留自己的工作区。加入多个工作区后，姓名下方会显示当前打开的工作区名称，选择它即可切换。

## 运行方式

- 每个项目在 Google Cloud 上自己的机器中运行，引擎与桌面应用相同。
- 网站步骤在那台机器上的真实 Chrome 中运行。你可以在页面上观看；需要自己登录网站时，选择 **接手操作**。
- 没有待办任务时机器会休眠，并在下一次计划运行前及时唤醒，无需打开页面。
- 项目的文件和登录信息加密保存在该项目自己的存储中，位于美国的 Google Cloud 爱荷华区域（`us-central1`）。保存哪些内容、保存在哪里，请参阅[隐私政策](/privacy/)。
- Kitewell 的内置模型只在总部位于美国或欧盟的零数据保留服务商上运行，你发送的内容不会被保存，也不会用于训练（[使用 Kitewell 的内置模型](/zh/docs/ai/#use-kitewells-included-model)）。

## 哪些在云端运行，哪些需要你的电脑

在 Kitewell Cloud 中运行：

- [网站](/zh/docs/browser/)，包括登录；
- [邮件](/zh/docs/email/)；
- 不含宏的 [Excel 文件](/zh/docs/spreadsheets/)；
- API 和 Web 请求；
- AI 模型步骤和助手；
- 审批，以及电脑合上时也会运行的[计划](/zh/docs/scheduling/)。

需要[电脑上的 Kitewell](/zh/docs/install/)：

- [桌面应用](/zh/docs/desktop/)；
- Excel 宏和查询刷新；
- 打印；
- 你自己磁盘上的文件；
- 只能从公司网络访问的网站；
- 保存在电脑上的客户端证书；
- 用你自己的订阅登录的 Claude Code、Codex 等编程智能体。

## 云端项目与桌面项目

在浏览器中创建的项目只能在浏览器中打开，电脑上的项目只能在桌面应用中打开。每个项目都在创建它的地方运行。
