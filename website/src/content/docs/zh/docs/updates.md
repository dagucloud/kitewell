---
title: 更新
---

Kitewell 会自动保持最新。它在后台下载新版本，确认该版本由 Kitewell 签名，然后在你不使用它的时候安装。正在运行的工作流在重启前后会一直运行下去。底层的工作流引擎 Dagu 随每个 Kitewell 版本一起提供，只在 Kitewell 更新时才会变化。

## 更新如何送达

**自动更新 Kitewell** 默认开启，位于 **此设备 → 设备设置 → 更新**。开启后，Kitewell 会：

1. 在打开一分钟后查找新版本，之后每六小时查找一次。
2. 在后台下载新版本并验证其签名。整个过程不显示任何内容。
3. 在下一个安全的时机安装：下次你退出 Kitewell、登录或重启电脑时，或者没有打开任何 Kitewell 窗口、或你已离开半小时的空闲时刻。菜单栏或托盘中的图标会消失几秒钟后重新出现，原本打开的窗口会重新打开到同一页面。

之后会收到一条通知，显示 **Kitewell 已更新到 x.y.z**；点击通知即可打开 kitewell.app 上的发布说明。

新版本会在两天内陆续推送到各台设备，因此并非每台电脑都在同一天收到。Kitewell 菜单（Mac 上为菜单栏菜单，Windows 上为托盘图标菜单）中的 **检查更新…** 会立即查找并马上获取新版本；如果没有新版本，则显示 **Kitewell 已是最新版本**。

## 更新会等待什么

更新从不打断工作。在以下情况下它会等待：

- 助手正在思考；
- 正在运行的工作流后面还有桌面步骤；
- 过去两分钟内有 MCP 客户端使用过 Kitewell；
- 某个 Kitewell 窗口中有未保存的编辑。

工作流从不阻止更新。它们会继续在启动时所用的引擎上运行，重启后的 Kitewell 会重新找到它们。

更新等待期间，Kitewell 菜单会显示 **重启以更新到 Kitewell x.y.z**，选择它会立即安装。它会询问未保存的编辑如何处理，并列出重启会中断的内容，提供 **立即重启** 和 **空闲时** 两个选项。如果更新已经等待了七天，会收到一条通知 **重启 Kitewell 以完成更新**；如果仅因未保存的编辑而等待了一天，会收到一条通知，请你保存或放弃这些编辑。编辑永远不会因为更新而被放弃。

## 关闭自动更新时

Kitewell 仍会检查。有新版本时，你会收到一条通知，菜单会显示 **更新到 Kitewell x.y.z…**。选择它即可下载该版本，菜单中会显示进度；之后 Kitewell 会提供 **重启以更新** 或 **稍后**。在你选择之前，不会安装任何内容。

## Dagu Cloud 需要更新的 Kitewell 时

Dagu Cloud 可能会停止为不再支持的版本提供服务。工作流、计划和本地 MCP 服务器会继续运行；同步、远程 MCP、Webhook 和运行状态会停止，直到这台电脑完成更新。窗口中的横幅会说明这一点，并提供 **立即更新**：无论设置如何，它都会立即获取新版本，并在下一个安全的时机安装，或在一小时后请你重启。

## 需要密码的 Mac

只有当你的 macOS 用户拥有这个应用并且可以写入“应用程序”文件夹时，Kitewell 才能在无需密码的情况下替换自身。如果你使用的是标准（非管理员）账户，或者 Kitewell 是由其他用户或设备管理工具安装的，就不会在后台下载任何内容。菜单会显示 **更新到 Kitewell x.y.z…**，并发送一条通知；选择它会下载更新，并显示 macOS 的管理员确认窗口。Kitewell 从不在你未请求时显示该确认窗口。

## 遇到问题时

- 下载或其验证失败。Kitewell 会在下次检查时悄悄重试。打开菜单即可看到原因。
- 安装失败。已安装的版本保持不变，Kitewell 会重新启动它；下一个安全的时机会再次尝试。同一版本安装失败三次后，Kitewell 会停止尝试该版本，并显示 **Kitewell 无法更新**，附有指向[下载页面](/zh/download/)的链接。
- 检查失败。请检查你的网络和[版本发布状态](/zh/releases/)。在你的系统的首个公开版本发布之前，没有可读取的更新源；无法连接更新源的检查会如实说明，而不会声称你已是最新版本。
- 你需要退回到以前的版本。旧的安装程序保留在 [GitHub 发布页面](https://github.com/dagucloud/kitewell/releases)上。安装旧版应用并不会带回旧数据；如需旧数据，请恢复[备份](/zh/docs/backups/)。

报告问题时，请附上 Kitewell 版本、引擎版本和操作系统版本。侧边栏左下角会显示 Kitewell 版本。顶部栏中的标签会同时显示 Kitewell 版本和引擎版本。在 Mac 上，应用菜单中的 **关于 Kitewell** 会显示 Kitewell 版本；在 Windows 上，托盘菜单顶部会显示应用和服务的版本。

## 详细信息

- 公开版本在 Mac 上从 `https://kitewell.app/updates/macos/latest.json` 读取更新源，在 Windows 上从 `https://kitewell.app/updates/windows/latest.json` 读取。
- 检查和下载不会影响正在运行的工作流。只有安装才会导致重启。
- 下载会等到磁盘可用空间达到 2 GB，并且连接不是按流量计费时才进行。已下载但尚未安装的更新，会在该版本被暂停或替换时丢弃。
- 更新后的通知每个版本只出现一次，并且只在允许 Kitewell 发送通知时出现。
- 在 Windows 上，更新会在替换文件的几秒钟内停止后台服务，但不会停止其下的运行：每次运行都有自己的进程组。只有 **退出 Kitewell** 会取消运行。
- Kitewell 运行的引擎是内置于该版本 Kitewell 中的 Dagu 版本，其版本号写在发布说明和[第三方许可证页面](/third-party/)上。
