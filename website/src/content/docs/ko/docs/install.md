---
title: Kitewell 설치
---

Kitewell은 내 Mac 또는 Windows PC에 설치하는 앱 하나입니다. 설치는 몇 분이면 끝나고, 첫 워크플로를 만들 수 있는 빈 프로젝트가 준비됩니다.

## 준비할 것

- macOS 13 이상을 실행하는 Mac, 또는 Windows 10 버전 1809 이상이나 Windows 11을 실행하는 64비트 PC.
- 사용 중인 시스템용 설치 프로그램. 제공되는 설치 프로그램은 [다운로드 페이지](/ko/download/)에 나와 있습니다. 목록에 없는 시스템은 아직 패키지를 준비하고 있습니다.

계정은 필요 없으며, Python, Docker, AI 도구도 필요 없습니다. 이런 도구는 나중에 워크플로에서 쓰게 될 때만 설치하세요.

## Mac에 설치

1. [다운로드 페이지](/ko/download/)를 열고 사용 중인 Mac에 맞는 다운로드를 선택합니다. Apple 칩인지 Intel 칩인지는 **Apple 메뉴 → 이 Mac에 관하여**에서 확인할 수 있습니다.
2. 다운로드한 `.pkg` 파일을 열고 설치 프로그램의 안내를 따릅니다. 설치 프로그램은 Kitewell을 응용 프로그램 폴더에 넣으며, 관리자 비밀번호를 묻습니다.
3. 응용 프로그램 폴더에서 **Kitewell**을 엽니다.
4. **로그인하고 Kitewell의 AI 사용**을 선택합니다. 브라우저에 Dagu Cloud가 열리고 대조할 코드가 표시됩니다. 코드를 확인하면 Kitewell이 첫 프로젝트를 만들고, AI를 바로 쓸 수 있는 상태로 엽니다. API 키가 필요 없고, 14일 체험의 100 크레딧으로 시작합니다. 내 AI 키를 쓰거나 AI를 쓰지 않으려면 대신 **이 기기에서 시작**을 선택합니다.

Kitewell은 처음 실행될 때 **로그인 시 열기**를 켜므로, Mac을 다시 시작해도 일정이 계속 실행됩니다. 메뉴 막대 메뉴에서 언제든 끌 수 있습니다.

이제 [첫 워크플로를 만들어 보세요](/ko/docs/getting-started/).

## Windows에 설치

1. [다운로드 페이지](/ko/download/)를 열고 `Kitewell-<version>-win-x64-Setup.exe`를 다운로드합니다.
2. 다운로드한 파일을 엽니다. Kitewell은 새 게시자이므로 Windows가 SmartScreen 경고를 표시할 수 있습니다. 파일의 SHA256이 다운로드 옆에 표시된 값과 일치하는지 확인한 다음 **추가 정보**와 **실행**을 차례로 선택합니다.
3. Kitewell은 아무것도 묻지 않고 관리자 비밀번호도 요구하지 않은 채 내 사용자 계정에 설치되며, 설치가 끝나면 열립니다.
4. **로그인하고 Kitewell의 AI 사용**을 선택합니다. 브라우저에 Dagu Cloud가 열리고 대조할 코드가 표시됩니다. 코드를 확인하면 Kitewell이 첫 프로젝트를 만들고, AI를 바로 쓸 수 있는 상태로 엽니다. API 키가 필요 없고, 14일 체험의 100 크레딧으로 시작합니다. 내 AI 키를 쓰거나 AI를 쓰지 않으려면 대신 **이 기기에서 시작**을 선택합니다.

Kitewell은 처음 실행될 때 **로그인 시 시작**을 켜므로, PC를 다시 시작해도 일정이 계속 실행됩니다. 트레이 메뉴에서 언제든 끌 수 있습니다. 누군가 로그인하기 전에도 일정이 실행되게 하려면 **기기 설정**을 열고 **로그인하지 않아도 실행**을 켭니다. 작은 Kitewell 로그인 서비스를 설정하기 위해 Windows가 관리자 승인을 한 번 요청하며, 비밀번호는 필요 없습니다.

창을 닫아도 Kitewell은 멈추지 않습니다. 시계 옆의 작은 아이콘 모음인 트레이에서 계속 실행됩니다. 창을 다시 열려면 트레이의 Kitewell 아이콘을 왼쪽 클릭합니다.

이제 [첫 워크플로를 만들어 보세요](/ko/docs/getting-started/).

## 문제가 생기면

- Windows가 알 수 없는 게시자의 설치 프로그램이라고 표시합니다. 파일의 SHA256을 [다운로드 페이지](/ko/download/)의 값과 비교한 다음 **추가 정보**와 **실행**을 선택합니다. Windows가 서명이 *유효하지 않다*고 표시하면 실행하지 말고 [알려 주세요](/ko/support/).
- Kitewell이 설치되었는데 열리지 않습니다. Windows 스마트 앱 컨트롤은 서명되지 않은 Kitewell 빌드를 로드하지 않으며, 릴리스 페이지에서 내려받은 빌드에는 서명이 되어 있습니다. [문제 해결](/ko/docs/troubleshooting/#kitewell-was-installed-but-did-not-start)을 참조하세요.
- 창이 비어 있거나, Kitewell이 WebView2를 설치하라고 요청합니다. **WebView2 설치**를 선택합니다. 1분 정도 걸립니다. [문제 해결](/ko/docs/troubleshooting/#kitewell-asks-to-install-webview2)을 참조하세요.
- macOS가 설치 프로그램을 확인할 수 없다고 표시합니다. 설치를 중단하고, 다운로드 URL과 버전을 함께 적어 [표시된 메시지를 그대로 알려 주세요](/ko/support/).

## 이전 버전 위에 새 버전 설치

먼저 편집 내용을 저장하고, 실행 중인 워크플로가 끝나기를 기다리세요. 프로젝트, 실행, 로그인 시 시작 설정은 모두 유지되며, 이미 진행 중인 실행도 계속됩니다.

- Mac에서는 새 `.pkg`를 실행합니다. 설치 프로그램이 실행 중인 앱을 닫고 교체한 뒤 백그라운드 서비스를 다시 시작합니다. 편집기에서 저장하지 않은 초안은 사라집니다. 앱이 닫히지 않으면 메뉴 막대에서 **Kitewell 종료**를 선택한 뒤 설치 프로그램을 다시 실행합니다.
- Windows에서는 새 Setup.exe를 실행합니다. 실행 중인 Kitewell을 닫고 교체한 뒤 새 버전을 엽니다. 편집기에서 저장하지 않은 초안은 사라지므로 먼저 저장하세요. 로그인 서비스가 켜져 있으면 Kitewell이 다음에 열릴 때 서비스도 알아서 새 버전으로 올립니다.

Kitewell이 새 버전을 직접 가져오게 할 수도 있습니다. [업데이트](/ko/docs/updates/)를 참조하세요.

## 세부 사항

- Windows에서는 앱이 사용자별로 `%LOCALAPPDATA%\Kitewell.App`에 설치되며, 관리자 확인 창이 뜨지 않습니다. 데이터는 이와 별도로 `%LOCALAPPDATA%\Kitewell`에 저장됩니다. 확인 창이 필요한 것은 로그인 서비스뿐입니다. 로그인 서비스는 프로그램을 `C:\Program Files\Kitewell`로 복사하고, 데이터를 `C:\ProgramData\Kitewell`로 한 번 옮깁니다. [일정](/ko/docs/scheduling/#run-with-nobody-signed-in-windows)을 참조하세요.
- 무인 설치(`Setup.exe --silent`)는 아무것도 표시하지 않으며 관리자 확인 창도 띄우지 않습니다. 로그인 서비스는 기기 설정에서만 설정됩니다.
- Kitewell 창은 Microsoft Edge WebView2 런타임으로 만들어집니다. 런타임이 없으면 Kitewell이 열릴 때 설치를 제안합니다.
- **로그인 시 시작**은 새로 설치하면 켜지고, 업데이트를 거쳐도 트레이에서 마지막으로 설정한 상태가 유지됩니다.
- Mac에서는 `.pkg`가 응용 프로그램 폴더에 설치하기 때문에 관리자 비밀번호가 필요합니다. 대신 `Kitewell.app`을 내 `~/Applications` 폴더에 복사하면 비밀번호 없이 쓸 수 있습니다.
- Kitewell은 Apple 칩을 탑재한 Mac과 Intel 프로세서를 탑재한 Mac, 그리고 Intel 또는 AMD 프로세서를 탑재한 64비트 Windows PC용으로 빌드됩니다.
