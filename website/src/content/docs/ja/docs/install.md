---
title: Kitewell をインストールする
---

## 動作要件

- macOS 13 以降。
- Apple シリコンまたは Intel プロセッサを搭載した Mac。**アップルメニュー → このMacについて** で確認できます。
- パッケージを「アプリケーション」フォルダーにインストールするための管理者権限。

パッケージ版のアプリを使うのに Go、Node.js、Xcode は必要ありません。Python、Docker、コマンドライン型の AI エージェントなどのツールは、ワークフローで使う場合にのみインストールしてください。

## アプリをインストールする

1. [ダウンロードページ](/ja/download/)を開き、お使いの Mac のアーキテクチャを選びます。
2. ダウンロードした `.pkg` を開き、macOS のインストーラの指示に従います。
3. 「アプリケーション」フォルダーから **Kitewell** を開きます。
4. [最初のワークフローを作成](/ja/docs/getting-started/)します。無料のプロジェクトにはアカウントは必要ありません。

現在のリリース状況は[ダウンロードページ](/ja/download/)で確認してください。インストーラが掲載されていない場合、公開パッケージはまだ準備中です。

## 既存のインストールを更新する

インストールの前に編集内容を保存し、実行中のジョブが完了するのを待ってください。インストーラは、現在のユーザーが実行している Kitewell のアプリとサービスを再起動します。ワークスペースのデータと、ログイン時に起動する設定は保持されます。

アプリの更新手順については[更新](/ja/docs/updates/)を参照してください。macOS がインストーラを検証できないと表示した場合は、作業を中止し、ダウンロード URL とバージョンを添えて[表示されたメッセージをそのまま報告](/ja/support/)してください。
