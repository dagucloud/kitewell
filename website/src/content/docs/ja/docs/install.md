---
title: Kitewell をインストールする
---

Kitewell は macOS と Windows で動作します。現在のリリース状況は[ダウンロードページ](/ja/download/)で確認してください。お使いのシステム向けのインストーラーが掲載されていない場合、公開パッケージはまだ準備中です。

## macOS

### 動作要件

- macOS 13 以降。
- Apple シリコンまたは Intel プロセッサを搭載した Mac。**アップルメニュー → このMacについて** で確認できます。
- パッケージを「アプリケーション」フォルダーにインストールするための管理者権限。

パッケージ版のアプリを使うのに Go、Node.js、Xcode は必要ありません。Python、Docker、コマンドライン型の AI エージェントなどのツールは、ワークフローで使う場合にのみインストールしてください。

### アプリをインストールする

1. [ダウンロードページ](/ja/download/)を開き、お使いの Mac のアーキテクチャを選びます。
2. ダウンロードした `.pkg` を開き、macOS のインストーラの指示に従います。
3. 「アプリケーション」フォルダーから **Kitewell** を開きます。**このデバイスで始める** を選ぶか、[プロジェクトを同期](/ja/docs/cloud-sync/)する場合は **Dagu Cloud でサインイン** を選びます。Kitewell は **Start at login** をオンにし、メニューバーからスケジュールを実行し続けます。オフにするにはメニューバーのメニューを使います。
4. [最初のワークフローを作成](/ja/docs/getting-started/)します。無料のプロジェクトにはアカウントは必要ありません。

## Windows

### 動作要件

- Windows 10 バージョン 1809 以降、または Windows 11（64 ビット、x64）。
- Microsoft Edge WebView2。ほとんどの PC には既に入っています。未インストールの場合はインストーラーが導入し、それでも無い状態で Kitewell を開くと **Install WebView2** を案内します。
- 管理者権限は不要です。インストーラーは、お使いのユーザーアカウントに Kitewell をインストールします。

ほかに先立って用意するものはありません。Python、Docker、コマンドライン型の AI エージェントなどのツールは、ワークフローで使う場合にのみインストールしてください。

### アプリをインストールする

1. [ダウンロードページ](/ja/download/)を開き、`Kitewell-<version>-amd64-setup.exe` をダウンロードします。
2. インストーラーを開きます。Kitewell は新しい発行元のため、Windows が SmartScreen の警告を表示することがあります。ファイルの SHA256 がダウンロードページの値と一致することを確認してから、**詳細情報 → 実行** を選びます。
3. インストーラーの指示に従います。管理者の確認なしに、お使いのユーザーアカウント用として `%LOCALAPPDATA%\Programs\Kitewell` にインストールされ、**Start Kitewell when you sign in**（サインイン時に Kitewell を起動する）の選択肢が表示されます。
4. インストールが終わると Kitewell が開きます。**このデバイスで始める** を選ぶか、[プロジェクトを同期](/ja/docs/cloud-sync/)する場合は **Dagu Cloud でサインイン** を選びます。Kitewell は初回起動時に **Start at login** をオンにし、トレイからスケジュールを実行し続けます。オフにするにはトレイメニューを使います。ウィンドウを閉じても Kitewell はトレイ（通知領域）で動き続けます。もう一度開くには、トレイアイコンを左クリックします。
5. [最初のワークフローを作成](/ja/docs/getting-started/)します。無料のプロジェクトにはアカウントは必要ありません。

## 既存のインストールを更新する

インストールの前に編集内容を保存し、実行中のワークフローが完了するのを待ってください。ワークスペースのデータとログイン時に起動する設定は保持され、実行中の処理はそのまま続きます。

- macOS では、インストーラは実行中の Kitewell アプリを閉じ（保存していない下書きは失われます）、サービスを再起動します。アプリが閉じない場合は、Kitewell を終了してからもう一度インストーラを実行してください。
- Windows では、インストーラーは実行中の Kitewell に終了を求めます。エディターに保存していない変更があれば、先に破棄してよいか Kitewell が確認します。その後アプリを置き換え、完了すると新しいバージョンを開きます。Kitewell がまだ実行中だとインストーラーが表示した場合は、トレイメニューから Kitewell を終了してから、もう一度インストーラーを実行してください。

アプリの更新手順については[更新](/ja/docs/updates/)を参照してください。macOS がインストーラを検証できないと表示した場合や、Windows がインストーラーの署名を無効と表示した場合は、作業を中止し、ダウンロード URL とバージョンを添えて[表示されたメッセージをそのまま報告](/ja/support/)してください。
