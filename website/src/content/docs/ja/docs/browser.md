---
title: Web サイトを自動操作
---

**Web サイトを自動操作** ステップは、ブラウザーでサイトを開き、自然な言葉で指示した操作を進めます。ページを開く、クリックや入力をする、情報を集める、ページの表示を確かめる、ファイルをダウンロードする、といったことができます。各ページで何をするかは API モデルが判断します。

## 最初の実行の前に

- **Chrome**：Google Chrome を `/Applications` にインストールするか、**デバイス設定 → ブラウザー → ブラウザーの実行ファイル** を設定します。
- ステップまたは **デバイス設定** にある **ブラウザーを確認** は、Kitewell のバックグラウンドサービスからブラウザーを一度開き、スケジュール実行で回答が必要になる前に macOS の確認を済ませます。macOS がまだ開くことを許可していないブラウザーやエンジンも知らせます。
- **モデル**：ステップで選ぶか、ワークフローの **設定** で **ブラウザーステップの既定モデル** を設定します。Anthropic、OpenAI、Gemini のモデルを使ってください。小さなローカルモデルでは、通常ブラウザーを操作できません。ブラウザーステップは、ページのテキストとレイアウトをこのモデルに送ります。ブラウザーが入力する値とシークレットが送られることはありません。

## ステップを組み立てる

操作を順に追加します。

- **ページを開く**
- **ページで操作する**（自然な言葉で指示します）
- **情報を集める**（文字列、数値、はい / いいえ、リストとして後続のステップに渡します）
- **次を確認する…**（ページがその状態でないとステップを失敗にします）
- **待機**
- **スクリーンショットを撮る**
- **私に入力を求める**（人の回答を待って実行を一時停止します）

**実行条件と制限時間** で、操作に条件を付けたり所要時間を制限したりできます。顧客番号など、ステップに入力させる値は **ブラウザーが入力する値** に登録し、指示の中では `%name%` と書きます。機密の値にはここでシークレットを選んでください。指示、モデル、ログのいずれにも含まれません。

## ブラウザーの設定

- **実行をまたいでサインインを保つ** は、Cookie とストレージをこのデバイスに保存し、サインインを保ちます。バックアップにはサインインは含まれず、並列で処理するループの項目どうしで共有することもできません。
- **ブラウザーウィンドウを表示する** は、組み立て中に便利です。スケジュール実行では非表示にしてください。
- **スクリーンショットを保存** は、ステップが失敗したとき、毎ステップの後、または保存しない、から選び、実行の成果物に保存します。
- **許可する Web サイト** は、ブラウザーが開けるホストを列挙したものに限ります。サイトが使うサインイン用や画像用のサーバーも含めてください。
- **ウィンドウの幅** と **ウィンドウの高さ** でページの大きさを決めます。

一度だけサインインするには、**一度サインインしてから収集** の例から始めます。最初のステップがサインインを待ち、以降の実行はそのサインインを使います。保存されたサインインは **プロジェクト設定 → ストレージ → サインイン** に一覧され、**サインインを削除…** で削除できます。

## リプレイ

うまくいった操作は記憶され、以降の実行ではモデルに尋ねずに再現されます。速く、モデルの費用もかかりません。サイトが変わって再現した操作が失敗すると、あらためてモデルに尋ねます。**毎回あらためて判断する** で操作ごとにリプレイを止められ、**プロジェクト設定 → ストレージ → リプレイキャッシュ** で記憶した操作を消去できます。実行には、各ステップの操作のうちいくつが再現されたかが表示されます。**情報を集める** と自然な言葉による確認は、毎回モデルに尋ねます。

## 質問に答える

**私に入力を求める** は実行を一時停止します。**実行とログ → 待機中** から開き、**回答** するか、**却下** でステップを失敗にします。回答は実行とともに記録されるため、パスワードは入力せず、シークレットを使ってください。回答する前にブラウザーが閉じた場合は、**ブラウザーステップを再開する** で最初の操作からやり直します。

スクリーンショットとダウンロードしたファイルは、実行の成果物に表示されます。
