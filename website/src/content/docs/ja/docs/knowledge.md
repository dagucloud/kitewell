---
title: ナレッジ
---

ナレッジは、プロジェクトのメンバーとアシスタントがワークフローについて書き留めたものです。各ワークフローの目的と結果を使う人、なぜその作りなのか、過去に何が壊れてどう直したか、そしてチームのシステム、用語、ルールを残します。アシスタントは答える前にナレッジを読み、作業に合わせて最新に保ちます。次の会話も次の担当者も、チームがすでに知っていることから始められます。

ナレッジには、ワークフローの定義からは分からないことを書きます。ステップ、スケジュール、入力はワークフローにあり、ページにはその理由を書きます。

## ナレッジを開く

サイドバーの**ナレッジ**には、プロジェクトのページが新しい順に並び、その横に開いているページが表示されます。検索では、タイトルや本文の言葉でページを探せます。全角と半角のどちらで入力しても見つかります。各ページには、関連するワークフローと最後に変更した人が表示されます。

同じページは、役に立つ場所にも表示されます。

- ワークフローエディターの**ナレッジ**タブには、そのワークフローに関するページが表示されます。
- 失敗した実行では、エラーの下に**関連ナレッジ**が表示されます。過去に何が壊れてどう直したかが書かれていることがよくあります。

## ページを書く・編集する

**新しいページ**を選び、タイトルを付けて入力します。編集ボタンや保存ボタンはありません。入力を止めて少しすると自動で保存され、ページの上の表示が**保存中…**から**保存済み**に変わります。⌘S（Ctrl+S）ですぐに保存でき、ページを離れたときにも保存されます。新しいページはタイトルを付けると作成されます。タイトルのないまま離れると、最初の行がタイトルになります。

- **書式**：選択したテキストの上に出るツールバーを使うか、`/` を入力して見出し、リスト、チェックリスト、引用、コード、表、区切り線を挿入します。空の行の横にある **+** でも同じメニューが開きます。入力中は Markdown のショートカットも使えます。`## ` で見出し、`- ` でリスト、`1. ` で番号付きリストになります。日本語入力のままでも、`・`、`＃`、`１．`、`／` で同じことができます。
- **ワークフローの関連付け**：**ワークフローを追加**から検索して選びます。関連付けたワークフローをクリックすると開きます。取引先の Web サイトやチームのルールのように、特定のワークフローに関係しないページもあって構いません。
- **リンク**は `https://` のアドレスだけが開きます。
- **貼り付け**では、ページが持てる形に整えます。表計算ソフトからコピーした表は 1 行目を見出しにした表に、Markdown のテキストは書式付きのテキストに、エディターからコピーしたコードはコードブロックになります。
- **⋯ → Markdown で編集**で、ページを Markdown のまま編集できます。画像や HTML を含むページは、エディターで表示できないため、この表示で開きます。
- **⋯ → ページを削除**で、プロジェクトの全員からページを削除します。

ページはあえて短く保ちます。タイトルは 60 文字まで、本文は 2,000 文字まで、関連付けられるワークフローは 20 件まで、ページは 1 プロジェクトにつき 100 件までです。上限が近づくと文字数が表示されます。残りは別のページに分けてください。

## アシスタントがすること

- **毎回読む**：アシスタントは、すべてのページの 1 行の要約と、開いているワークフローやページに関するページの全文を読みます。ほかのページも必要に応じて読みます。
- **作業しながら書く**：続く事実、ルール、訂正を伝えたとき、定義からは分からない理由でワークフローを変えたとき、失敗が直ったときに、すぐページに保存します。パネルには**ナレッジを更新しました**という記録が、**元に戻す**と**開く**付きで表示されます。ワークフローを新しく作るときは、そのページも同じカードに載り、**適用**で両方が保存されます。
- **外部の内容を読んだあとは先に確認する**：会話で Web ページや実行の出力を読んだあとは、ページの変更を内容付きのカードで提案し、**適用**を選ぶまで何も保存しません。Web ページやログにある文章が、気付かないうちに全員のナレッジに入ることはありません。
- **変えた箇所を見せる**：そのページを開いていれば、変更された部分に印が付き、**元に戻す**と**保持**が表示されます。入力を始めると印は消えます。
- **事実だけを書く**：書くのは、あなたが言ったことや決めたこと、実行で確かめられたことだけで、あなたが使う言語で書きます。ページとワークフロー自体の内容が食い違うときはワークフローが正しく、アシスタントがページを直します。

ページは参考資料としてアシスタントに渡され、指示として扱われることはありません。

## ほかの人がページを変えたとき

入力中のページを、チームの誰か、別のデバイス、またはアシスタントが変更しても、入力した内容は失われません。ページにその旨が表示され、**自分の版を残す**か**相手の版を使う**かを選べます。相手の版にしたあとも ⌘Z（Ctrl+Z）で戻せます。Dagu Cloud に接続できないときのように保存できない編集は、**保存されていません**と表示されたままページに残ります。ページを離れても、Kitewell を開いている間に同じページを開くと戻ってきます。

## 見られる人

プロジェクトのナレッジは全員が読め、編集者とアシスタントが変更できます。ページはプロジェクトに属し、[Dagu Cloud と同期](/ja/docs/cloud-sync/)され、[プロジェクトのエクスポート](/ja/docs/sharing/)にも含まれます。[リリース](/ja/docs/releases/)には含まれません。[MCP クライアント](/ja/docs/mcp/)は `read` に `target: "knowledge"` を指定して読めます。**編集と実行** の権限があれば、`change` で作成、置き換え、削除もできます。
