---
title: バッチ
---

バッチは、シートの行ごとに 1 つのワークフローを 1 回ずつ実行します。顧客、物件、ページ、ファイルなど、処理したい項目を行に並べます。各行はその行の入力でワークフローを実行し、結果列には各実行で見つかった値が集まります。

## シートを作る

サイドバーの**その他 → バッチ**を開いて**新しいシート**を選び、ワークフローを選んでシート名を付けます。ワークフローの実行ダイアログから始めることもできます。**単独実行**から**バッチシート**に切り替えると、入力済みの値が新しいシートの共通の入力になります。

シートには、ワークフローのパラメーターごとに 1 つの入力列があり、型、既定値、選べる値もそのまま引き継がれます。**ラベル**は行の名前で、ワークフローには渡されません。ワークフローが宣言していないパラメーターも受け付ける場合は、**その他の入力（JSON）**列でそれらを JSON オブジェクトとして指定します。

1 つのシートには最大 5,000 行、結果列は最大 30 列まで入ります。

## 行を追加する

- **入力または貼り付け**：セルを直接編集するか、スプレッドシートからコピーしたセルを、選択中のセルを起点に貼り付けます。必要に応じて行が追加されます。
- **取り込む**：セルや 1 行 1 値のテキストを貼り付けるか、CSV ファイルを選びます。各列を入力、**ラベル**、または**列をスキップ**に割り当てます。入力名と一致する見出しは自動で割り当てられます。
- **共通の入力**：行が独自の値を持たない限り、すべての行が使う値です。空のセルには、使われる共通の値またはワークフローの既定値が灰色で表示されます。

値は入力の型に従って読み取られます。文字列はそのまま、数値、`true` または `false`、リストやオブジェクトは JSON として扱います。ワークフローの変更後に整数の入力へ文字列が残っている場合など、型に合わない値は削除されず、理由とともに赤枠で示されます。シートは引き続き保存され、その行だけが値を直すまで実行されません。

シートは編集するそばから保存されます。

## 行を実行する

実行ボタンは、まだ実行していない行、または選択した行を開始します。**その他の実行方法**から、失敗した行の再実行、前回の実行から変更された行、すべての行を選べます。

開始する前に、すべての行がワークフローのパラメーターに照らして確認されます。必須の入力が欠けている行や、ワークフローが受け付けない値を持つ行があると何も開始されず、その行に理由が表示されます。

その後、各行はワークフローのキューで個別の実行になります。バナーには、完了した行数、同時に実行される数、ワークフローが共有キューを使う場合はそのキュー名、何行か完了した後はおおよその残り時間が表示されます。**default** キューはプロジェクト全体で同時に 5 件まで実行します。この数は**キュー**ページで変更できます。

- **待機中の行をキャンセル**は、まだ待っている行をキャンセルします。実行中の行は続きます。
- **すべて停止**は、実行中の行も停止します。

実行を開始すると、その時点のワークフローと各行の値の写しが保存されます。後からシートやワークフローを編集しても、キューに入った実行は変わりません。前回の実行から入力が変わった行には**変わっています**と表示され、**前回の実行から変更あり**フィルターで一覧できます。**実行とログ**から行の実行を再試行したり、ステップの状態を変更したりすると、その行にも反映されます。

## 結果を集める

結果列は、各実行から見つけたい値を 1 つ表します。**結果列を追加**を選び、名前を付け、型（**文字列**、**数値**、**はい / いいえ**、**選択**、**段階**）を選び、単位や値が複数あるときにどれを取るかなど、読み取る内容を説明します。

結果列は、**エージェントとモデル**の API モデルが埋めます。**モデルを選ぶ**で次を設定します。

- **抽出モデル**は、文字列と数値の列を読み取ります。判断モデルがない場合は、それ以外の列も読み取ります。各値には実行からの引用が付き、引用が一字一句そのままでは見つからなかった場合はその旨が示されます。
- **判断モデル**は任意です。はい / いいえ、選択、段階の列を確率付きで判断します。引用はありませんが、より速く低コストです。**この確信度未満は「要確認」にする**で、確認が必要な判断の基準を決めます。

値は、各実行が成功した後に読み取られます。モデルには実行の出力、ログ、テキストファイルが送られるため、それらを任せられるプロバイダーを選んでください。**N 行を埋める**は、値が欠けている完了済みの行を読み取り、行の詳細にある**もう一度読み取る**は、1 つの実行を読み直します。どちらもワークフローを再実行しません。列を変更する前に読み取った値は、古い値として示されます。

## 書き出し、複製、削除

- **CSV を書き出す**は、入力、値、各判断の確率、各行の実行を保存します。
- シートのメニュー（**⋯**）には、同じ行、入力、結果列、モデルを持つ写しを作る**複製**と、同じ設定で空の行を 1 つだけ持つ**行なしで複製**があります。値はそれを生んだ実行に属するため、写しは結果のない状態で始まります。
- **シートを削除**は、シートと、このデバイスで読み取った値を削除します。実行は**実行とログ**に残ります。バッチの実行中は、そのシートを削除できません。

## アラート、アシスタント、MCP

- Kitewell Pro では、**バッチを完了したとき**の[アラート](/ja/docs/alerts/)で、実行のすべての行が終わったこと、成功しなかった行の数が知らされます。バッチの行は、人の対応を待つ場合を除き、1 行ずつ実行のアラートを出しません。
- アシスタントは、行や列の追加・変更を提案できます。提案は、適用する、適用して対象の行を実行する、または却下するまで、開いているシートに表示されます。適用した変更は元に戻せます。
- [MCP クライアント](/ja/docs/mcp/)は、シートの一覧表示と読み取り、作成・置き換え・削除、行の実行、値の読み取り、実行のキャンセルができます。

## このデバイスに残るもの

シート自体はプロジェクトに属するため、プロジェクトの書き出しに含まれ、[Dagu Cloud と同期](/ja/docs/cloud-sync/)されます。行の状態と、実行から読み取った値は、実行したデバイスに残ります。
