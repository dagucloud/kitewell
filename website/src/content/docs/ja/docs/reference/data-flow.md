title: データの流れのリファレンス
---

Kitewell が届きうるすべての送り先、そこが受け取るもの、そしてそれを止める方法です。[コンピューターの外に出るもの](/ja/docs/data-flow/)の詳しい版です。

## データの行き先

それぞれについて、送られるもの、送り先、止める方法を示します。

- **モデルのステップ、アシスタント、失敗の診断、モデルが読むシートの列。** プロンプトと、それが読む材料を送ります。実行の出力、渡したログと成果物、ページの表示テキストとレイアウト、画面全体のスクリーンショット、シートの行の入力とその実行の結果、失敗した実行のステップと定義、プロジェクトのナレッジです。送り先は[エージェントとモデル](/ja/docs/ai/)で選んだモデルのプロバイダー。止めるには、モデルを追加しないか、自分で動かすサーバーをモデルに指定します。AI のステップがないワークフローは何も送りません。
- **はい／いいえ、選択肢、段階で判定するシートの列。** 同じ材料と、各列の問いおよび各選択肢の意味を送ります。送り先は判定モデルのプロバイダー（OpenRouter、TypeSafe、または自分で指定したアドレス）。止めるには、公開された値を写す列を代わりに選びます。モデルを必要としません。
- **AI エージェントに依頼するタスク。** プロンプトと、エージェントが作業フォルダーで読んだものを、そのツール自身の規約に従って送ります。送り先は、そのコマンドラインツールがサインインしているサービス。止めるには、別のタスクを使います。
- **アドレスを指定した [API のインポート](/ja/docs/apis/)、またはアシスタントへの Web ページの確認の依頼。** その文書やページを取得するだけのリクエストを、認証情報を添えずに送ります。送り先は指定したアドレス。止めるには、アドレスではなく OpenAPI のファイルをアップロードします。
- **Web サイト、コマンド、ファイル、API、Docker、リモートのステップ。** そのステップが送るものを送ります。送り先は、ステップが指定したサイト、サーバー、API、イメージレジストリ、コンピューター。止めるには、そのステップを削除します。
- **メールのステップ。** メール本文と、依頼した検索条件を送ります。送り先は、メールボックス自身のメールサーバーか、Google のメールボックスなら Gmail API。サインインは Google か Microsoft に届きます。止めるには、**メールアカウント** でメールボックスの接続を解除します。
- **[アラート](/ja/docs/alerts/)。** 何が起きたか、緊急度、プロジェクト、ワークフロー、戻るためのリンクを送ります。送り先は、自分のメールサーバー、Slack や Teams のアドレス、PagerDuty、自前の Webhook。止めるには、そのチャンネルを削除します。
- **Dagu Cloud へのサインイン。** ワークスペースのプラン、Kitewell のバージョン、このコンピューターの ID と名前を 6 時間ごとに送ります。送り先は、Descarty が運営する Dagu Cloud。止めるには、**デバイス設定** で **サインアウト** します。
- **[プロジェクトの同期](/ja/docs/cloud-sync/)。** そのプロジェクトのワークフロー、モデル、サーバー、API 接続、キュー、レジストリ、シークレットの名前と説明、シート、ナレッジのページ、リリースを送ります。メールボックスを扱うワークフローについては、サインインしている誰のデバイスが実行するかも送ります。送り先は Dagu Cloud。止めるには、そのプロジェクトの **同期を停止** します。
- **[Kitewell に接続した ChatGPT や Claude](/ja/docs/mcp/)。** 接続したアプリが Kitewell のツールに尋ねたものを送ります。ワークフロー、実行とそのログ、成果物、シート、ナレッジ、そして編集権限があれば、このコンピューターにある Excel ファイルの行です。送り先は、Kitewell のリレー（`mcp.kitewell.app`）を通じてそのアプリへ。止めるには、**リモートアクセス** をオフにするか、アプリを **失効させる** を選びます。
- **アプリや API キーが購読したイベント。** イベントごとに、プロジェクト、ワークフロー、実行、終わり方、日時、失敗したステップの名前、待っているステップの質問、シートの実行の集計、スケジュールを逃した理由を送ります。送り先は、購読側が指定したアドレス。止めるには、その購読を **削除** します。
- **ワークフローの Webhook。** 出ていくものはありません。リクエストが届き、ヘッダーと本文のまま、Kitewell のリレー（`hooks.kitewell.app`）で最大 7 日間、このコンピューターが取りに来るまで待ちます。止めるには、その Webhook を **オフにする** を選びます。
- **更新の確認。** あなたや作業について何も含まないリクエストを送ります。送り先は、ワークフローエンジンは GitHub、Kitewell アプリは kitewell.app。エンジンの確認は **エンジンの自動更新** をオフにすると止まります。アプリの確認は、自分で行ったときだけです。
- **Windows の Install WebView2。** ダウンロードのリクエストを Microsoft に送ります。通常はインストーラーがランタイムを同梱しているため、ランタイムがないときだけ現れます。

Kitewell がこれ以外に送るものはありません。アプリには利用状況の計測、クラッシュの報告、アナリティクスのいずれもなく、Descarty が実行で扱う業務データを受け取ることもありません。

## コンピューターから出ないもの

| 何が | どこにあるか |
| --- | --- |
| シークレットの値 | 各プロジェクトのエンジンに暗号化して保存され、ログではマスクされ、読み戻し、エクスポート、バックアップ、同期のいずれもされません。同期したプロジェクトが運ぶのは名前と説明だけで、値は各コンピューターが持ちます。[シークレット](/ja/docs/secrets/)を参照してください |
| サインイン | メールボックスの接続、保存した Web サイトのサインイン、SSH の鍵とホストの信頼、イメージレジストリのパスワード。いずれも暗号化されるか、あなたのユーザーだけが読めるファイルに置かれ、バックアップには含まれません |
| 実行、ログ、成果物 | データフォルダーに、プロジェクトごとに既定で 30 日間。[実行とログ](/ja/docs/runs/)を参照してください。同期されるのは定義だけで、実行は同期されません |
| アシスタントの会話と失敗の診断 | データフォルダーに、プロジェクトごとに |
| Excel のブック | ファイルがあるコンピューター上でそのまま読み書きされます。リンクしたシートが運ぶのはファイル名とどのコンピューターにあるかだけで、セルは含まれません。パス、どの行に結果を戻すか、元に戻すために保持しているコピーは、そのコンピューターに残ります。[Excel を自動化](/ja/docs/spreadsheets/)を参照してください |
| ワークフローの定義とナレッジ | エクスポート、共有、同期をするまで、データフォルダーに |

これらについて 2 つ知っておいてください。[ダウンロードした](/ja/docs/backups/)スナップショットには、実行の出力、アシスタントの会話、元に戻すための Excel のコピーが入っています。ダウンロードしたスナップショットは、機密のファイルとして扱ってください。

また、モデルや接続したアプリにブックを読ませれば、セルはコンピューターの外に出ます。これについては「境界を知っておく」で説明します。

## AI をどこで動かすか選ぶ

すべての AI 機能は、[エージェントとモデル](/ja/docs/ai/)で追加したモデルを指定します。Kitewell 自身はモデルもキーも持っていません。

- プロバイダーは、Anthropic、OpenAI、Google Gemini、OpenRouter、Z.ai、OpenCode Zen、または Ollama や vLLM のように自分で動かす OpenAI 互換サーバーです。判定モデルは OpenRouter か TypeSafe を使います。
- 自分のサーバーなら、プロンプト、ページのテキスト、スクリーンショットはネットワークの中にとどまります。小さなローカルモデルでは通常ブラウザーやデスクトップを操作できないので、タスクごとに選んでください。
- OpenRouter 経由では、Kitewell 自身が行う読み取り、つまりアシスタント、失敗の診断、シートの結果列は、受け取った内容を保存も学習もしないプロバイダーにだけ振り分けるよう OpenRouter に求めます。ワークフローの中のモデルのステップはエンジンが送るので、この指定は行われません。

Web サイトやデスクトップのステップが入力するパスワードなどの値は `%name%` と書かれます。モデルに届くのは名前だけです。

## 境界を知っておく

- ワークフローは Kitewell を実行している人の権限で動きます。コマンドのステップは、データフォルダーを含め、あなたが読めるものをすべて読めます。信頼できる定義とコマンドだけを実行してください。
- デスクトップのステップのスクリーンショットには、画面上のすべてのウィンドウが写ります。見られてはいけないものは閉じるか、ほかの人が作業しないコンピューターを使ってください。
- メールは信頼できない入力です。メールの本文がコマンドや、コマンドを実行するエージェントに渡ると、その動作を操られる恐れがあります。**確認して実行** は、そうしたワークフローに警告します。
- Webhook のリクエストも信頼できない入力で、URL を知っている人は誰でもそのワークフローを開始できます。Kitewell は、まだ送信者の署名を検証しません。[Webhook でワークフローを開始する](/ja/docs/webhooks/)を参照してください。
- アシスタントや接続したアプリに Excel のファイルを読ませると、そのセルは外に出ます。ファイルからシートを組むときは列の一覧と最大 10 行、名前を指定して依頼したときはその行そのものです。
- バックアップとプロジェクトのエクスポートは暗号化されません。シークレットの値とサインインは含まれませんが、定義、シート、ナレッジ、実行の出力、設定は書かれたまま入っています。共有ストレージに移す前に、自分で暗号化してください。
- Slack のアドレスなど、アラートチャンネルの認証情報は、システムのキーチェーンではなく、あなたのユーザーだけが読めるファイルに保存されます。
- MCP や REST によるリモートアクセスは、このコンピューターのローカルアドレスにしか届きません。例外は、Kitewell のリレーを通じた ChatGPT と Claude、そして自分で HTTPS を前に置いたクライアントです。[MCP と API アクセス](/ja/docs/mcp/)を参照してください。

## データフォルダーの場所

- macOS: `~/Library/Application Support/Kitewell/`
- Windows: `%LOCALAPPDATA%\Kitewell\`

各部分に何が入っているかは[バックアップと復旧](/ja/docs/backups/)に、すべてを削除する方法は[アンインストール](/ja/docs/uninstall/)にあります。

## 詳細

### モデルのプロバイダー

モデルのステップが届くのは、`api.anthropic.com`、`api.openai.com`、`generativelanguage.googleapis.com`、`openrouter.ai`、`api.z.ai`、`opencode.ai`、または自分で指定したベースアドレスです。判定モデルは `openrouter.ai/api/alpha` か `api.typesafe.ai/v1` に、HTTPS だけで届きます。モデルのフォームでプロバイダーを選ぶと、OpenRouter か OpenCode Zen から、そのプロバイダーが公開しているモデルの一覧も取得します。このリクエストにはキーも、あなたに関する情報も含まれません。

シートの読み取りが送るのは、1 行あたり最大 48 KiB です。その行のラベルと入力、各ステップの結果、実行が公開した出力、実行が作ったテキストファイル最大 5 件、最後のステップと失敗したステップのログの末尾です。

### Dagu Cloud

リクエストは `console.dagu.sh` に、HTTPS で、`User-Agent: Kitewell/<version>` を添えて届きます。256 KiB を超える同期ドキュメントは、Dagu Cloud が返す署名付きアドレスを通じて、そのストレージにアップロードされます。このコンピューターのクラウド資格情報は、データフォルダー直下に設定と並んで置かれたファイルで、バックアップには入りません。

### リレー

リレーは Cloudflare の Worker で、デバイスごとに 1 つのオブジェクトを持ちます。接続はコンピューター側から WebSocket で張るので、ネットワーク上で受信を待ち受けるものはありません。

リレーが保存するのは、このコンピューターの名前、Kitewell のバージョン、最後に確認した時刻、ツール一覧の呼び出しへの直近の応答で、デバイスから最後に連絡があってから 30 日後にすべて削除されます。MCP のリクエストと応答は、保存されずに通過します。

例外は Webhook の本文とヘッダーで、デバイスが取りに来るまで保存されます。保持は最大 7 日、待機は最大 1,000 件、本文は 512 KiB、ヘッダーは 16 KiB、1 つの URL につき毎分 60 リクエストまでです。

Webhook のトークンはハッシュだけが保存されます。リレー自身はログを書きません。Webhook は Kitewell Personal と Team の機能です。

イベントの配信はリレーを通りません。このコンピューターから購読側のアドレスへ直接行われます。HTTPS のみ、公開アドレスのみ、プロキシなし、リダイレクトなし、最大 256 KiB で、Standard Webhooks の形式で署名され、最大 24 時間まで再試行されます。

### 更新

エンジンの確認は `api.github.com` から `dagucloud/dagu` の最新リリースを読み、ダウンロードはそのリポジトリの GitHub のリリースファイルから行われます。

Kitewell アプリはビルド時に指定された HTTPS のアドレスからマニフェストを読み、インストーラーを実行する前に SHA-256 を検証します。Windows の **Install WebView2** は、Microsoft 自身のブートストラッパーを `go.microsoft.com` から取得し、Microsoft の署名を確認してから実行します。

### 保存時の暗号化

シークレットは、このデバイスに鍵を置いたエンジンの AES-256-GCM レジストリを使います。メールボックスのパスワードとリフレッシュトークンは、デバイスごとの鍵 `mail.key` のもとで AES-256-GCM により封じられ、この鍵はどのバックアップにも入りません。データフォルダーとバックアップフォルダーは、あなたのユーザーアカウントだけが読めます。
