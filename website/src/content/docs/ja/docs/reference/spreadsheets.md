title: Excel リファレンス
---

[Excel を自動化](/ja/docs/spreadsheets/)が省いた、ブックに関するすべてです。スプレッドシートのステップはすべてのプランで使えます。

## ブックの使い方は 2 通り

シートの行として使う方法。ブックをシートにリンクすると、各行が 1 回の実行になり、その結果が元の行に戻ります。ブックそのものが仕事（片付けるべき一覧）であるときに向いています。

ワークフローのステップとして使う方法。タスクの選択画面の **スプレッドシート** のグループからタスクを追加し、ファイルのパスを指定すると、実行のその時点で読み書きします。

ブックが大きな仕事の一部であるとき（メールで届いたファイル、テンプレートから作る毎月の請求書）に向いています。

## Kitewell が読めるもの

現場にあるブックをそのまま読めます。表の上のタイトル行、2 行にまたがる結合ヘッダー、途中の小計、下にある注記、全角数字、和暦の日付、先頭のゼロが残る郵便番号。表がどこにあり、各列が何を持つかは Kitewell が判断します。

ブックをリンクするとき、プレビューの各行に **3 行目を列名にする** が並び、見出しのない一覧には **列名なし** もあります。列名より上の行、空の行、合計行は取り込まず、それぞれ件数が示されます。

合計行を含めるチェックと、Excel で非表示の行を除くチェックもあります。

**行を見つけ直す基準** で選べるのは、値が重複せず空でもない列だけで、ほかは「値が重複または空」として選択できません。**行の位置** も選べますが、その場合は結果を待っている間に並べ替えや行の挿入をしないでください。

## 自分のファイルに戻るもの

シートに書き戻し先と同じ名前の列があればそれを使い、新しい名前なら右端に列を追加します。実行 ID や内部キーの列、セルのコメントは追加しません。**実行日時** は `2026-10-01 09:30` の形式です。

言葉はブックのヘッダーの言語に合わせます。ヘッダーが日本語のシートには 状態・エラー・実行日時 と、済 / 一部失敗 / 失敗 / 中止 / 却下 が入ります。

Excel が保存せずに閉じてロックファイルだけ残した場合は、**開いていません** でそれを片付けられます。日本語のファイル名のコピーには `(results)` ではなく `(結果)` が付きます。

**元に戻す** は、書き込みの後にブックを編集していた場合、編集を捨てないために拒否し、現在のファイルを `supplier-invoices (before undo).xlsx` として横に残します。

**ブックをもう一度読む** は「新規 1 行 · 更新 1 行 · 1 件がシートにありません」のように結果を報告します。ヘッダー行から、キー列や入力が使う列がなくなっている場合は、読み取りを中止して、なくなった列を名指しします。列を選び直すには、ブックをもう一度リンクしてください。

**リンクを解除** するとつながりが終わり、行はシートに残り、結果はブックに戻らなくなります。

## スプレッドシートのステップ

ワークフローの中では、タスクの選択画面の **スプレッドシート** のグループに 10 個のタスクがあります。

| タスク | 内容 |
| --- | --- |
| スプレッドシートを読む | シートの行を、必要な行だけ、各列を文字・数値・日付として読み取ります |
| スプレッドシートを検査する | セルに誤りがあれば、何かが起きる前に止めます |
| 結果を書き戻す | 状態や値を、元の行に書き込みます |
| スプレッドシートを書き出す | 新しいブックやシートを作成、置き換え、または追記します |
| スプレッドシートに行を追加する | 最後の行の下に、見出しに合わせて行を追加します |
| テンプレートに記入する | テンプレートのセルや名前付きセルに記入し、コピーとして保存します |
| スプレッドシートを変換する | シートを CSV（UTF-8 または Shift_JIS）、JSON、JSON Lines に変換します |
| シートの追加・コピー・名前変更・削除 | テンプレートのシートから月を始めます。再実行しても安全です |
| ブックの構成を調べる | 後のステップのために、シート・見出し・型を調べます |
| フォームを読む | 見積や注文など、フォーム形式のシートから項目を読み取ります。レイアウトは問いません |

ステップで **ブック** を選ぶと、シートがタブで並び、最初の 20 行がそのステップが読む形に変換されて表示され、検出した表とヘッダー行も示されます。

**チェック** は、実行する前に、このコンピューターでそのステップが失敗しないか（ブック、シート、列が見つかるか）をエンジンに問い合わせます。答えに出てくるセル番地はボタンになっていて、そのセルを表示できます。

**テスト** は読んだ行を表として見せます。書き込み系のステップはテスト中は変更内容を報告するだけで、**テスト中もファイルを保存する** にチェックしない限り保存しません。例外は「スプレッドシートを変換する」で、テストでも出力ファイルを実際に書き出します。

後続のステップから参照する列には、「請求書番号」に対する `invoice` のような、半角英字の短い名前が必要です。**スプレッドシートを読む** の各列にある **後のステップ用の名前** に入力します。エディターが名前を提案します。

書き込み系のステップには 3 つの設定があります。**ドライラン** は保存せずに変更内容だけを報告します。待ち時間を数分まで指定でき、Excel で開かれているブックはその時間だけ再試行してからステップが失敗します。一時ファイルを経由した保存は既定でオンで、書きかけのブックを残しません。

## 同じ仕事をステップで組む

ブックが大きなワークフローの一部であるときは、リンクしたシートの代わりに、請求書の仕事をステップとして組み立てます。

1. **スプレッドシートを読む** で「請求書」シートを読みます。**次の条件の行だけ…** で「状態」列を選び、値を空のままにすると、未処理の請求書だけが読まれます。
2. **各項目を処理** で、その行を 1 行ずつ回します。
3. ループの中に、請求書をポータルに登録するステップを置きます。[Web サイトのステップ](/ja/docs/browser/)、[デスクトップのステップ](/ja/docs/desktop/)、あるいはコマンドです。このステップが受付番号を出します。
4. 同じくループの中の **結果を書き戻す** が、その請求書の行の「状態」に「済」を、「受付番号」に受付番号を書き込みます。

書き戻しがループの中にあるので、失敗した行は「状態」が空のまま残り、次の実行で拾い直されます。間にどのステップを置いても、スプレッドシートのステップは画面を使いません。

## 表ではなくフォーム

見積や注文のようにフォーム形式で組まれたシート（見出しの下に行が並ぶのではなく、ラベルと値がシート上に散らばっているもの）は **フォームを読む** で読み取ります。

**このフォームの内容と、見つけたい項目** にフォームの説明を書きます。**見つける項目** に、各項目の名前、型、シート上のラベルの見え方を、シートの言語で書きます。

モデルは各項目がどのセルにあるかを答え、エンジンがそのセルから値を読むので、値が作られることはありません。

**セルの値をモデルに送る** をオフにすると、モデルには各セルにどんな種類のものがあるかだけが見え、金額や日付はこのコンピューターに残ります。

**このレイアウトを記憶し、同じフォームはモデルなしで読む** は既定でオンで、同じテンプレートにはそれ以上モデルの呼び出しがかかりません。**記憶したセルを忘れる** を選ぶと次の実行で改めて尋ねます。フォームのレイアウトが変わったときや、項目が違うセルから読まれたときに使います。

## プライバシー

- ブックはこのコンピューター上で Kitewell が読みます。ファイルはアップロードされず、パスがデバイスの外に出ることもありません。
- **このファイルから設定する** は、開いているブックからワークフローを作るようアシスタントに頼みます。列名、各列で見つかった型、最初の 10 行（各セルは 1 行に切り詰め）を送ります。**列名だけを送る** なら列名だけです。
- パスワード付きのブックは、このコンピューターでだけ開かれます。パスワードは **パスワード（シークレットの参照）** に[シークレット](/ja/docs/secrets/)の参照として保持され、ワークフローに書かれることも、ログに残ることもありません。保護されたブックはプレビューできず、Excel でパスワードを外すまで取り込めません。
- [Dagu Cloud との同期](/ja/docs/cloud-sync/)で運ばれるリンクは、ファイル名、シート、どのデバイスにあるか、列の対応付けだけで、パスは含みません。シートの行はいっしょに同期され、その行にはブックから読んだセルの値が入っています。
- ファイルのパス、各行が Excel のどの行から来たか、実行から読んだ結果、元に戻すために保持しているコピーは、シートを実行したデバイスに残ります。[ワークスペースのバックアップ](/ja/docs/backups/)にはこのコピーも含まれます。

全体像は[コンピューターの外に出るもの](/ja/docs/data-flow/)を参照してください。

## 制限

- `.xlsx` と `.xlsm`。`.xls` や `.ods` は、先に Excel で `.xlsx` として保存してください。
- 1 回の読み取りは 5,000 行、約 900 KB までです。超えると、ステップは何を残したかを伝え、範囲を狭める、列を減らす、行を絞り込むよう求めます。
- シートは 5,000 行と 30 個の結果列まで、ループは 1,000 項目までです。取り込むファイルは最大 16 MiB です。
- リンクしたブックの非表示の行は、ほかの行と同じく読まれます。除外できるのは取り込んだファイルだけです。
- ファイルにすでにあるグラフ、ピボットテーブル、条件付き書式、入力規則は保持されますが、新しく作ることはなく、ピボットテーブルは更新されません。Windows ではマクロのステップで更新できます。
- Google スプレッドシートにはまだ対応していません。

Web サイトやデスクトップアプリを操作するステップには、そのアプリが必要です。画面を使わないのはスプレッドシートのステップだけです。
