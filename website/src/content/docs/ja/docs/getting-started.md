---
title: 最初のワークフロー
---

このガイドでは、ローカルでコマンドを実行するワークフローを作成します。外部サービスには接続せず、AI のアカウントも必要ありません。

## ジョブを作成する

1. Kitewell を開きます。初回起動時は **このデバイスで始める** を選んでプロジェクトを作成します。2 回目以降は、サイドバーでプロジェクトを選びます。
2. **ジョブを作成** を選び、名前を **Morning check-in** にします。
3. 最初のタスクとして **コマンドまたはスクリプトを実行** を選びます。
4. 次のコマンドを入力します。

```sh
printf 'Kitewell is ready.\n'
```

グラフには、タスクのつながりが表示されます。タスクを選択すると、右側のインスペクターでその項目を編集できます。タスクを追加するには、グラフの **+** を使います。

## 確認して実行する

**確認して実行** を選び、続けて **保存して実行…** を選びます。入力を確認して **実行を開始** を選択します。**実行とログ** を開くと、結果とタスクの出力を確認できます。

保存と実行は別々の操作です。**保存** はワークフローを検証して保存しますが、実行は開始しません。**ツール → ワークフローを確認** は、インストールされているエンジンで下書きを検証します。

## スケジュールを追加する

ワークフローに戻り、**スケジュール** を開いて毎日の実行時刻とタイムゾーンを選び、保存します。**保存済みのスケジュールを有効にする** がオンになっていることを確認してください。スケジュールした時刻には、コンピューターをスリープさせず、Kitewell を起動したままにしてください。

無人での実行に頼る前に、[スケジュール](/ja/docs/scheduling/)を確認してください。

## 自分の作業を取り込む

サンプルのコマンドを、普段使っているスクリプトに置き換えます。アプリの環境は対話型のターミナルセッションとは異なる場合があるため、必要に応じて実行ファイルや作業フォルダーには絶対パスを使ってください。実行ごとに変わる値には入力フィールドを追加し、認証情報は[シークレット](/ja/docs/secrets/)に保存します。

Docker イメージ、AI エージェント、人による判断、サーバーグループ上のコマンドをつなぐ方法は、[ワークフローを組み立てる](/ja/docs/workflow-builder/)を参照してください。
