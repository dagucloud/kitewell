---
title: Kitewell Cloud
---

Kitewell Cloud は、インストールせずにブラウザーで使える Kitewell です。ここで作ったプロジェクトには、それぞれクラウド上の専用のマシンがつくので、パソコンを閉じていてもスケジュールどおりに動きます。ワークフローは、ブラウザーやスマホから作って直せます。

## はじめる

1. [app.kitewell.com](https://app.kitewell.com/) を開き、Dagu Cloud にサインインします。アカウントがなければ作成します。
2. **プロジェクトを作成** を選び、名前をつけます。Kitewell がプロジェクトのマシンを用意します。20 秒ほどかかります。
3. [最初のワークフロー](/ja/docs/getting-started/)と同じように、やってほしい仕事をアシスタントに伝えます。

最初のプロジェクトを作ると、14 日間の無料トライアルが始まります。カード登録は不要です。トライアルで作れるプロジェクトは 1 つです。もっと作るには Kitewell Personal か Team に登録してください。

## しくみ

- プロジェクトごとに、Google Cloud 上の専用のマシンで動きます。エンジンはデスクトップアプリと同じ Kitewell です。
- Web サイトのステップは、そのマシンの本物の Chrome で動きます。ページで様子を見られ、サイトに自分でサインインするときは **操作を代わる** を選びます。
- 予定がないあいだマシンは休み、次のスケジュール実行に間に合うように起きます。ページを開いておく必要はありません。
- プロジェクトのファイルとサインインは、そのプロジェクト専用のストレージに暗号化して保存されます。保存場所は、アメリカ合衆国にある Google Cloud のアイオワリージョン（`us-central1`）です。何をどこに保存するかは[プライバシーポリシー](/ja/privacy/)をご覧ください。

## クラウドで動くもの、パソコンが必要なもの

Kitewell Cloud で動くもの：

- [Web サイト](/ja/docs/browser/)（サインインを含む）
- [メール](/ja/docs/email/)
- マクロのない [Excel ファイル](/ja/docs/spreadsheets/)
- API と Web リクエスト
- AI モデルのステップとアシスタント
- 承認と、パソコンを閉じていても動く[スケジュール](/ja/docs/scheduling/)

[パソコンの Kitewell](/ja/docs/install/) が必要なもの：

- [デスクトップアプリ](/ja/docs/desktop/)
- Excel のマクロとクエリの更新
- 印刷
- 自分のディスクにあるファイル
- 社内ネットワークからしか開けないサイト
- パソコンに入っているクライアント証明書
- 自分のサブスクリプションでサインインした Claude Code や Codex などのコーディングエージェント

## クラウドのプロジェクトとデスクトップのプロジェクト

ブラウザーで作ったプロジェクトはブラウザーでだけ、パソコンのプロジェクトはデスクトップアプリでだけ開けます。どちらも、作った場所で動きます。
