---
title: コンピューターの外に出るもの
---

Kitewell はあなたのコンピューターで動きます。ワークフロー、実行履歴、ログ、シークレット、サインインはデータフォルダーにあり、あなたが選んだステップ、同期、サインインが送らない限り、どこにも送信されません。このページでは、何がいつどこへ出ていくのかを送り先ごとに示します。

## データの行き先

| 送り先 | 受け取るもの | いつ |
| --- | --- | --- |
| あなたが選んだ AI プロバイダー | タスクが読むもの：プロンプトとその文脈、実行の出力、渡したログと成果物、ページの表示テキストとレイアウト（Web サイトのステップ）、画面全体のスクリーンショット（デスクトップのステップ）、シートの行（モデルが読み取る結果列。公開値を写す列は何も送りません）、失敗した実行のステップとワークフロー（失敗の診断）、プロジェクトのナレッジ（アシスタント：すべてのページの要約と、開いているものに関するページ） | タスク、アシスタント、診断、シートがそのモデルを使ったときだけ |
| コマンドラインエージェントのプロバイダー | プロンプトと、エージェントが作業フォルダーで読んだもの。そのツール自身の規約に従います | **AI エージェントに頼む** タスクの実行時 |
| サイト、サーバー、API、メールボックス | ステップが送るもの | それらのステップの実行時 |
| Dagu Cloud（Descarty） | ワークスペースのプラン確認、Kitewell のバージョン、このコンピューターの ID と名前（6 時間ごと）。同期したプロジェクトの定義、シークレットの名前と説明、シート、ナレッジ | サインイン後のみ。プロジェクトのデータは、そのプロジェクトを同期した後のみ |
| Kitewell のリレーを通じた ChatGPT や Claude | 接続したアプリが Kitewell のツールで読むもの。リレー（mcp.kitewell.app、Cloudflare 上）は呼び出しを保存せずに通し、保存するのはこのコンピューターの名前、Kitewell のバージョン、最後に確認した時刻、直近のツール一覧だけです | [アプリを接続](/ja/docs/mcp/#connect-chatgpt-or-claude)した後、リモートアクセスがオンの間だけ |
| Webhook のための Kitewell のリレー | コンピューターからは何も送りません。ほかのサービスがワークフローの Webhook の URL に送ったリクエストは、コンピューターが受け取るまで、最大 7 日間リレー（hooks.kitewell.app、Cloudflare 上）で待ちます。リレーが保存するのは、各 URL の秘密の部分のハッシュだけです | [Webhook をオンにした](/ja/docs/webhooks/)後だけ |
| ChatGPT が MCP Events 用に指定したアドレス | 購読したイベントごとに、プロジェクト、ワークフロー、実行の ID、ステータス、日時、失敗したステップの名前、待っているステップの質問やタスクの文章 | イベントが起きたとき |
| kitewell.app と GitHub | 更新の確認と、ダウンロードするインストーラー | 更新の確認時と、インストール時 |

Kitewell 自身がこれ以外に送るものはありません。アプリに利用状況の計測はなく、Descarty が実行で処理される業務データを受け取ることもありません。

## 残るもの

- **シークレットの値。** 各プロジェクトのエンジンに暗号化（AES-256-GCM）して保存され、ログではマスクされ、読み戻し、エクスポート、バックアップ、同期のいずれもされません。同期したプロジェクトが運ぶのはシークレットの名前と説明だけで、値は各デバイスが持ちます。[シークレット](/ja/docs/secrets/)を参照してください。
- **サインイン**：メールボックスの接続、保存した Web サイトのサインイン、SSH の鍵とホストの信頼、レジストリのパスワードは、デバイスにとどまり、バックアップに含まれません。
- **実行、ログ、成果物。** プロジェクトごとに、既定で 30 日間データフォルダーに保存されます。[実行とログ](/ja/docs/runs/)を参照してください。同期されるのは定義だけで、実行は同期されません。
- **アシスタントの会話、失敗の診断、シートに読み込んだ値。** デバイスに保存されます。
- **Excel のブック。** ファイルがあるコンピューター上でそのまま読み書きされ、アップロードされることはありません。リンクしたシートが持ち運ぶのはファイル名とどのコンピューターにあるかだけで、セルの中身は含まれません。パス、元に戻すためのコピー、どの行に結果を戻すかは、そのコンピューターに残り、エクスポートやバックアップにも含まれません。何かが送られるのは、アシスタントにファイルからシートを組ませるときだけで、列名とその型、最大 10 行（または列名のみ）です。[Excel を自動化](/ja/docs/spreadsheets/)を参照してください。
- **ワークフローの定義とナレッジ**は、エクスポート、共有、同期するまでデバイスにとどまります。

## AI をどこで動かすか選ぶ

すべての AI 機能は、[エージェントとモデル](/ja/docs/ai/)で追加したモデルを指定します。AI タスクのないワークフローは、どのプロバイダーにも何も送りません。

- **プロバイダー**：Anthropic、OpenAI、Google Gemini、OpenRouter、Z.ai、OpenCode Zen、または Ollama や vLLM のような OpenAI 互換サーバー。
- **自前のサーバー**なら、プロンプト、ページのテキスト、スクリーンショットはネットワークの中にとどまります。小さなローカルモデルでは通常ブラウザーやデスクトップを操作できないので、タスクごとに選んでください。
- **OpenRouter 経由**のアシスタントの依頼は、依頼を保存も学習もしないプロバイダーにだけ送られます。

Web サイトやデスクトップのステップが入力するパスワードなどの値は `%name%` と書かれ、モデルには届きません。届くのは名前だけです。

## 境界を知っておく

- ワークフローは Kitewell を実行しているユーザーの権限で動きます。コマンドのステップは、データフォルダーを含め、あなたが読めるものをすべて読めます。信頼できる定義とコマンドだけを実行してください。
- デスクトップのステップのスクリーンショットには、画面上のすべてのウィンドウが写ります。見られてはいけないものは閉じるか、ほかの人が作業しないコンピューターを使ってください。
- メールは信頼できない入力です。メールの本文がコマンドや、コマンドを実行するエージェントに渡ると、その動作を操られる恐れがあります。**確認して実行** は、そうしたワークフローに警告します。
- バックアップとプロジェクトのエクスポートは暗号化されません。シークレットの値とサインインは含まれませんが、ワークフローの定義、シート、ナレッジ、設定は書かれたまま入っています。共有ストレージに置く前に、自分で暗号化してください。
- Slack の Webhook など、アラートチャンネルの認証情報は、システムのキーチェーンではなく、あなたのユーザーだけが読めるファイルに保存されます。
- MCP や REST によるリモートアクセスは、このコンピューターのローカルアドレスにしか届きません。例外は、Kitewell のリレーを通じて接続した ChatGPT と Claude と、自分で HTTPS を前に置いたクライアントです。[MCP と API アクセス](/ja/docs/mcp/)を参照してください。
- ワークフローの Webhook の URL を持つ人は誰でも、そのワークフローを開始できます。[Webhook でワークフローを開始する](/ja/docs/webhooks/)を参照してください。

## セキュリティ審査のために

IT 部門やセキュリティ審査向けの要約は、Descarty の[セキュリティのページ](https://descarty.com/security/)にあります。セキュリティチェックシートでよく聞かれる質問への回答は、[Kitewell セキュリティ概要](https://descarty.com/resources/)にまとめています。

## データフォルダーの場所

- macOS: `~/Library/Application Support/Kitewell/`
- Windows: `%LOCALAPPDATA%\Kitewell\`

各部分に何が入っているかは[バックアップと復旧](/ja/docs/backups/)に、すべてを削除する方法は[アンインストール](/ja/docs/uninstall/)にあります。
