---
title: コンピューターの外に出るもの
---

Kitewell はあなたのコンピューターで動きます。ワークフロー、実行履歴、ログ、シークレット、サインインはデータフォルダーにあり、あなたが選んだステップ、同期、サインインが送らない限り、どこにも送信されません。このページでは、何がいつどこへ出ていくのかを送り先ごとに示します。

## データの行き先

| 送り先 | 受け取るもの | いつ |
| --- | --- | --- |
| あなたが選んだ AI プロバイダー | タスクが読むもの：プロンプトとその文脈、実行の出力、渡したログと成果物、ページの表示テキストとレイアウト（Web サイトのステップ）、画面全体のスクリーンショット（デスクトップのステップ）、シートの行（モデルが読み取る結果列。公開値を写す列は何も送りません）、失敗した実行のステップとワークフロー（失敗の診断）、プロジェクトのナレッジ（アシスタント：すべてのページの要約と、開いているものに関するページ） | タスク、アシスタント、診断、シートがそのモデルを使ったときだけ |
| コマンドラインエージェントのプロバイダー | プロンプトと、エージェントが作業フォルダーで読んだもの。そのツール自身の規約に従います | **AI エージェントに頼む** タスクの実行時 |
| サイト、サーバー、API、メールボックス | ステップが送るもの | それらのステップの実行時 |
| Dagu Cloud（Descarty） | ワークスペースのプラン確認と Kitewell のバージョン（6 時間ごと）。同期したプロジェクトの定義、シークレットの名前と説明、シート、ナレッジ | サインイン後のみ。プロジェクトのデータは、そのプロジェクトを同期した後のみ |
| kitewell.app と GitHub | 更新の確認と、ダウンロードするインストーラー | 更新の確認時と、インストール時 |

Kitewell 自身がこれ以外に送るものはありません。アプリに利用状況の計測はなく、Descarty が実行で処理される業務データを受け取ることもありません。

## 残るもの

- **シークレットの値。** 各プロジェクトのエンジンに暗号化（AES-256-GCM）して保存され、ログではマスクされ、読み戻し、エクスポート、バックアップ、同期のいずれもされません。同期したプロジェクトが運ぶのはシークレットの名前と説明だけで、値は各デバイスが持ちます。[シークレット](/ja/docs/secrets/)を参照してください。
- **サインイン**：メールボックスの接続、保存した Web サイトのサインイン、SSH の鍵とホストの信頼、レジストリのパスワードは、デバイスにとどまり、バックアップに含まれません。
- **実行、ログ、成果物。** プロジェクトごとに、既定で 30 日間データフォルダーに保存されます。[実行とログ](/ja/docs/runs/)を参照してください。同期されるのは定義だけで、実行は同期されません。
- **アシスタントの会話、失敗の診断、シートに読み込んだ値。** デバイスに保存されます。
- **ワークフローの定義とナレッジ**は、エクスポート、共有、同期するまでデバイスにとどまります。

## AI をどこで動かすか選ぶ

すべての AI 機能は、[エージェントとモデル](/ja/docs/ai/)で追加したモデルを指定します。プロバイダーは Anthropic、OpenAI、Google Gemini、OpenRouter、Z.ai、OpenCode Zen、または Ollama や vLLM のような、このコンピューターや自社ネットワークで動かす OpenAI 互換サーバーです。ローカルサーバーなら、プロンプト、ページのテキスト、スクリーンショットはネットワークの中にとどまります。小さなローカルモデルでは通常ブラウザーやデスクトップを操作できないので、タスクごとに選んでください。AI タスクのないワークフローは、どのプロバイダーにも何も送りません。

Web サイトやデスクトップのステップが入力するパスワードなどの値は `%name%` と書かれ、モデルには届きません。届くのは名前だけです。

## 境界を知っておく

- ワークフローは Kitewell を実行しているユーザーの権限で動きます。コマンドのステップは、データフォルダーを含め、あなたが読めるものをすべて読めます。信頼できる定義とコマンドだけを実行してください。
- デスクトップのステップのスクリーンショットには、画面上のすべてのウィンドウが写ります。見られてはいけないものは閉じるか、ほかの人が作業しないコンピューターを使ってください。
- メールは信頼できない入力です。メールの本文がコマンドや、コマンドを実行するエージェントに渡ると、その動作を操られる恐れがあります。**確認して実行** は、そうしたワークフローに警告します。
- バックアップとプロジェクトのエクスポートは暗号化されません。シークレットの値とサインインは含まれませんが、ワークフローの定義、シート、ナレッジ、設定は書かれたまま入っています。共有ストレージに置く前に、自分で暗号化してください。
- Slack の Webhook など、アラートチャンネルの認証情報は、システムのキーチェーンではなく、あなたのユーザーだけが読めるファイルに保存されます。
- MCP や REST によるリモートアクセスは、自分で HTTPS を前に置かない限り、このコンピューターのローカルアドレスにしか届きません。[MCP と API アクセス](/ja/docs/mcp/)を参照してください。

## データフォルダーの場所

- macOS: `~/Library/Application Support/Kitewell/`
- Windows: `%LOCALAPPDATA%\Kitewell\`

各部分に何が入っているかは[バックアップと復旧](/ja/docs/backups/)に、すべてを削除する方法は[アンインストール](/ja/docs/uninstall/)にあります。
