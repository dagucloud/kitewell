---
title: コンピューターの外に出るもの
---

Kitewell はあなたのコンピューターで動きます。ワークフロー、実行履歴、ログ、シークレット、サインインは、そのコンピューター上のフォルダーにあり、あなたが用意したステップ、同期、サインインが送らない限り、どこにも出ていきません。このページでは、Kitewell が届きうる送り先、そこが受け取るもの、そしてそれを止める方法をすべて示します。

## データの行き先

| これを使ったとき | 送られるもの | 送り先 | 止める方法 |
| --- | --- | --- | --- |
| モデルのステップ、アシスタント、失敗の診断、モデルが読むシートの列 | プロンプトと、それが読む材料：実行の出力、渡したログと成果物、ページの表示テキストとレイアウト、画面全体のスクリーンショット、シートの行の入力とその実行の結果、失敗した実行のステップと定義、プロジェクトのナレッジ | [エージェントとモデル](/ja/docs/ai/)で選んだモデルのプロバイダー | モデルを追加しない、または自分で動かすサーバーをモデルに指定する。AI のステップがないワークフローは何も送りません |
| はい／いいえ、選択肢、段階で判定するシートの列 | 同じ材料と、各列の問いおよび各選択肢の意味 | 判定モデルのプロバイダー：OpenRouter、TypeSafe、または自分で指定したアドレス | 代わりに、公開された値を写す列を選ぶ。モデルを必要としません |
| **AI エージェントに依頼** のタスク | プロンプトと、エージェントが作業フォルダーで読んだもの。そのツール自身の規約に従います | そのコマンドラインツールがサインインしているサービス | 別のタスクを使う |
| アドレスを指定した [API のインポート](/ja/docs/apis/)、またはアシスタントへの Web ページの確認の依頼 | その文書やページを取得するだけのリクエスト。認証情報は添えません | 指定したアドレス | アドレスではなく、OpenAPI のファイルをアップロードする |
| Web サイト、コマンド、ファイル、API、Docker、リモートのステップ | そのステップが送るもの | ステップが指定したサイト、サーバー、API、イメージレジストリ、コンピューター | そのステップを削除する |
| メールのステップ | メール本文と、依頼した検索条件 | メールボックス自身のメールサーバー、または Google のメールボックスなら Gmail API。サインインは Google か Microsoft に届きます | **メールアカウント** でメールボックスの接続を解除する |
| [アラート](/ja/docs/alerts/) | アラートの内容：何が起きたか、緊急度、プロジェクト、ワークフロー、戻るためのリンク | 自分のメールサーバー、Slack や Teams のアドレス、PagerDuty、自前の Webhook | そのチャンネルを削除する |
| Dagu Cloud へのサインイン | ワークスペースのプラン、Kitewell のバージョン、このコンピューターの ID と名前（6 時間ごと） | Descarty が運営する Dagu Cloud | **デバイス設定** で **サインアウト** する |
| [プロジェクトの同期](/ja/docs/cloud-sync/) | そのプロジェクトのワークフロー、モデル、サーバー、API 接続、キュー、レジストリ、シークレットの名前と説明、シート、ナレッジのページ、リリース。メールボックスを扱うワークフローについては、サインインしている誰のデバイスが実行するかも | Dagu Cloud | そのプロジェクトの **同期を停止** する |
| [Kitewell に接続した ChatGPT や Claude](/ja/docs/mcp/) | 接続したアプリが Kitewell のツールに尋ねたもの：ワークフロー、実行とそのログ、成果物、シート、ナレッジ。編集権限があれば、このコンピューターにある Excel ファイルの行も | Kitewell のリレー（`mcp.kitewell.app`）を通じて、そのアプリへ | **リモートアクセス** をオフにする、またはアプリを **失効させる** |
| アプリや API キーが購読したイベント | イベントごとに、プロジェクト、ワークフロー、実行、終わり方、日時、失敗したステップの名前、待っているステップの質問、シートの実行の集計、スケジュールを逃した理由 | 購読側が指定したアドレス | その購読を **削除** する |
| ワークフローの **Webhook** | 出ていくものはありません。リクエストが届き、ヘッダーと本文のまま、このコンピューターが取りに来るまでリレーで待ちます | Kitewell のリレー（`hooks.kitewell.app`）が最大 7 日間保持します | その Webhook を **オフにする** |
| 更新の確認 | あなたや作業について何も含まないリクエスト | ワークフローエンジンは GitHub、Kitewell アプリは kitewell.app | **エンジンの自動更新** をオフにする。アプリの確認は、自分で行ったときだけです |
| Windows の **Install WebView2** | ダウンロードのリクエスト | Microsoft | 通常はインストーラーが同梱しているため、ランタイムがないときだけ現れます |

Kitewell がこれ以外に送るものはありません。アプリには利用状況の計測、クラッシュの報告、アナリティクスのいずれもなく、Descarty が実行で扱う業務データを受け取ることもありません。

## コンピューターから出ないもの

| 何が | どこにあるか |
| --- | --- |
| シークレットの値 | 各プロジェクトのエンジンに暗号化して保存され、ログではマスクされ、読み戻し、エクスポート、バックアップ、同期のいずれもされません。同期したプロジェクトが運ぶのは名前と説明だけで、値は各コンピューターが持ちます。[シークレット](/ja/docs/secrets/)を参照してください |
| サインイン | メールボックスの接続、保存した Web サイトのサインイン、SSH の鍵とホストの信頼、イメージレジストリのパスワード。いずれも暗号化されるか、あなたのユーザーだけが読めるファイルに置かれ、バックアップには含まれません |
| 実行、ログ、成果物 | データフォルダーに、プロジェクトごとに既定で 30 日間。[実行とログ](/ja/docs/runs/)を参照してください。同期されるのは定義だけで、実行は同期されません |
| アシスタントの会話と失敗の診断 | データフォルダーに、プロジェクトごとに |
| Excel のブック | ファイルがあるコンピューター上でそのまま読み書きされます。リンクしたシートが運ぶのはファイル名とどのコンピューターにあるかだけで、セルは含まれません。パス、どの行に結果を戻すか、元に戻すために保持しているコピーは、そのコンピューターに残ります。[Excel を自動化](/ja/docs/spreadsheets/)を参照してください |
| ワークフローの定義とナレッジ | エクスポート、共有、同期をするまで、データフォルダーに |

これらについて 2 つ知っておいてください。[ダウンロードした](/ja/docs/backups/)スナップショットには、実行の出力、アシスタントの会話、元に戻すための Excel のコピーが入っています。ダウンロードしたスナップショットは、機密のファイルとして扱ってください。また、モデルや接続したアプリにブックを読ませれば、セルはコンピューターの外に出ます。これについては「境界を知っておく」で説明します。

## AI をどこで動かすか選ぶ

すべての AI 機能は、[エージェントとモデル](/ja/docs/ai/)で追加したモデルを指定します。Kitewell 自身はモデルもキーも持っていません。

- プロバイダーは、Anthropic、OpenAI、Google Gemini、OpenRouter、Z.ai、OpenCode Zen、または Ollama や vLLM のように自分で動かす OpenAI 互換サーバーです。判定モデルは OpenRouter か TypeSafe を使います。
- 自分のサーバーなら、プロンプト、ページのテキスト、スクリーンショットはネットワークの中にとどまります。小さなローカルモデルでは通常ブラウザーやデスクトップを操作できないので、タスクごとに選んでください。
- OpenRouter 経由では、Kitewell 自身が行う読み取り、つまりアシスタント、失敗の診断、シートの結果列は、受け取った内容を保存も学習もしないプロバイダーにだけ振り分けるよう OpenRouter に求めます。ワークフローの中のモデルのステップはエンジンが送るので、この指定は行われません。

Web サイトやデスクトップのステップが入力するパスワードなどの値は `%name%` と書かれます。モデルに届くのは名前だけです。

## 境界を知っておく

- ワークフローは Kitewell を実行している人の権限で動きます。コマンドのステップは、データフォルダーを含め、あなたが読めるものをすべて読めます。信頼できる定義とコマンドだけを実行してください。
- デスクトップのステップのスクリーンショットには、画面上のすべてのウィンドウが写ります。見られてはいけないものは閉じるか、ほかの人が作業しないコンピューターを使ってください。
- メールは信頼できない入力です。メールの本文がコマンドや、コマンドを実行するエージェントに渡ると、その動作を操られる恐れがあります。**確認して実行** は、そうしたワークフローに警告します。
- Webhook のリクエストも信頼できない入力で、URL を知っている人は誰でもそのワークフローを開始できます。Kitewell は、まだ送信者の署名を検証しません。[Webhook でワークフローを開始する](/ja/docs/webhooks/)を参照してください。
- アシスタントや接続したアプリに Excel のファイルを読ませると、そのセルは外に出ます。ファイルからシートを組むときは列の一覧と最大 10 行、名前を指定して依頼したときはその行そのものです。
- バックアップとプロジェクトのエクスポートは暗号化されません。シークレットの値とサインインは含まれませんが、定義、シート、ナレッジ、実行の出力、設定は書かれたまま入っています。共有ストレージに移す前に、自分で暗号化してください。
- Slack のアドレスなど、アラートチャンネルの認証情報は、システムのキーチェーンではなく、あなたのユーザーだけが読めるファイルに保存されます。
- MCP や REST によるリモートアクセスは、このコンピューターのローカルアドレスにしか届きません。例外は、Kitewell のリレーを通じた ChatGPT と Claude、そして自分で HTTPS を前に置いたクライアントです。[MCP と API アクセス](/ja/docs/mcp/)を参照してください。

## セキュリティ審査のために

IT 部門やセキュリティ審査向けの要約は、Descarty の[セキュリティのページ](https://descarty.com/security/)にあります。セキュリティチェックシートでよく聞かれる質問への回答は、[Kitewell セキュリティ概要](https://descarty.com/resources/)にまとめています。

## データフォルダーの場所

- macOS: `~/Library/Application Support/Kitewell/`
- Windows: `%LOCALAPPDATA%\Kitewell\`

各部分に何が入っているかは[バックアップと復旧](/ja/docs/backups/)に、すべてを削除する方法は[アンインストール](/ja/docs/uninstall/)にあります。

## 詳細

### モデルのプロバイダー

モデルのステップが届くのは、`api.anthropic.com`、`api.openai.com`、`generativelanguage.googleapis.com`、`openrouter.ai`、`api.z.ai`、`opencode.ai`、または自分で指定したベースアドレスです。判定モデルは `openrouter.ai/api/alpha` か `api.typesafe.ai/v1` に、HTTPS だけで届きます。モデルのフォームでプロバイダーを選ぶと、OpenRouter か OpenCode Zen から、そのプロバイダーが公開しているモデルの一覧も取得します。このリクエストにはキーも、あなたに関する情報も含まれません。

シートの読み取りが送るのは、1 行あたり最大 48 KiB です。その行のラベルと入力、各ステップの結果、実行が公開した出力、実行が作ったテキストファイル最大 5 件、最後のステップと失敗したステップのログの末尾です。

### Dagu Cloud

リクエストは `console.dagu.sh` に、HTTPS で、`User-Agent: Kitewell/<version>` を添えて届きます。256 KiB を超える同期ドキュメントは、Dagu Cloud が返す署名付きアドレスを通じて、そのストレージにアップロードされます。このコンピューターのクラウド資格情報は、データフォルダー直下に設定と並んで置かれたファイルで、バックアップには入りません。

### リレー

リレーは Cloudflare の Worker で、デバイスごとに 1 つのオブジェクトを持ちます。接続はコンピューター側から WebSocket で張るので、ネットワーク上で受信を待ち受けるものはありません。リレーが保存するのは、このコンピューターの名前、Kitewell のバージョン、最後に確認した時刻、ツール一覧の呼び出しへの直近の応答で、デバイスから最後に連絡があってから 30 日後にすべて削除されます。MCP のリクエストと応答は、保存されずに通過します。

例外は Webhook の本文とヘッダーで、デバイスが取りに来るまで保存されます。保持は最大 7 日、待機は最大 1,000 件、本文は 512 KiB、ヘッダーは 16 KiB、1 つの URL につき毎分 60 リクエストまでです。Webhook のトークンはハッシュだけが保存されます。リレー自身はログを書きません。Webhook は Kitewell Personal と Team の機能です。

イベントの配信はリレーを通りません。このコンピューターから購読側のアドレスへ直接行われます。HTTPS のみ、公開アドレスのみ、プロキシなし、リダイレクトなし、最大 256 KiB で、Standard Webhooks の形式で署名され、最大 24 時間まで再試行されます。

### 更新

エンジンの確認は `api.github.com` から `dagucloud/dagu` の最新リリースを読み、ダウンロードはそのリポジトリの GitHub のリリースファイルから行われます。Kitewell アプリはビルド時に指定された HTTPS のアドレスからマニフェストを読み、インストーラーを実行する前に SHA-256 を検証します。Windows の **Install WebView2** は、Microsoft 自身のブートストラッパーを `go.microsoft.com` から取得し、Microsoft の署名を確認してから実行します。

### 保存時の暗号化

シークレットは、このデバイスに鍵を置いたエンジンの AES-256-GCM レジストリを使います。メールボックスのパスワードとリフレッシュトークンは、デバイスごとの鍵 `mail.key` のもとで AES-256-GCM により封じられ、この鍵はどのバックアップにも入りません。データフォルダーとバックアップフォルダーは、あなたのユーザーアカウントだけが読めます。
