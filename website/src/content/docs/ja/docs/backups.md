---
title: バックアップと復旧
---

## バックアップを作成する

**このデバイス → バックアップ**を開き、**バックアップを作成**を選びます。アーカイブは、自分で管理できる場所にダウンロードしてください。バックアップの対象は、デバイス上のすべてのプロジェクトです。毎日バックアップするには、**デバイス設定 → 自動バックアップ → 毎日のバックアップ**をオンにし、**バックアップの時刻**を選びます。自動のスナップショットは最新の 10 件が保持され、手動のものは削除するまで残ります。

バックアップと復元は、実行中、キュー待ち、承認待ちを含む待機中の実行がなくなるまで待ちます。自動バックアップは 15 分ごとに再試行します。スナップショットを作成する間、プロジェクトのエンジンは短時間停止します。

同じデバイス上のバックアップは変更を元に戻すのに役立ちますが、そのデバイス自体を失った場合の備えにはなりません。必要に応じて、保護された別のコピーを保管してください。

## 含まれるもの

スナップショットには、ワークスペースの設定、プロジェクト、ワークフロー定義、インポートした OpenAPI 仕様と API 接続の設定、バッチシート、リリース、シークレット名、実行履歴、成果物が含まれます。API 接続はシークレットへの参照を保持します。スナップショットには、管理対象のシークレットの値とその復号キー、実行出力のログディレクトリ、ローカルの編集履歴、[Web サイト](/ja/docs/browser/)のサインインとリプレイキャッシュ、アラートの履歴、このデバイスの GUI ログインと API キーのハッシュは含まれません。スナップショットを復元すると、ローカルの編集履歴も消去されます。

アーカイブは暗号化されていません。ワークフロー定義、OpenAPI 仕様、ソース URL に直接入力した認証情報は削除されません。ダウンロードしたスナップショットは機密情報として扱ってください。

[アラート](/ja/docs/alerts/)のチャンネルとルールは含まれますが、それらの送信に使うシークレットは含まれません。メールサーバーのパスワード、Slack と Teams のアドレス、Webhook の URL と署名シークレット、PagerDuty のキーはデバイスに残ります。別のコンピューターで復元した後に、これらを再入力してください。

外部スクリプトとその入力ファイル、Docker ボリューム、マウントしたディレクトリ、サードパーティのサービスは、Kitewell のバックアップにはコピーされません。これらは別途バックアップしてください。クラウドのデバイス認証情報は、ワークスペースのバックアップから除外されます。

## 復元する

実行中の作業を終えてから**このデバイス → バックアップ**を開き、保存済みのスナップショットで**バックアップを復元**を選びます。復元すると安全用のバックアップが作成され、ワークスペースのデータと設定が置き換えられ、ワークスペースが再読み込みされます。このデバイスの GUI ログイン、API キー、停止中のプロジェクトはそのまま保持されます。

管理対象のシークレットは復元されません。復元後には、プロジェクトごとに再入力が必要なシークレットと、もう一度サインインが必要な Web サイトのステップが報告されます。対応が必要と報告された項目を確認してください。復元が Dagu Cloud に書き込むことはありません。[同期しているプロジェクト](/ja/docs/cloud-sync/)はバックアップ時点の状態に戻り、次の更新で Dagu Cloud のコピーを取り込みます。アーカイブの上限は、展開後のデータで 2 GiB です。

## 容量の使いみちを確認する

**プロジェクト設定 → ストレージ** には、プロジェクトが使っている容量とディスクの空き容量が表示され、空きが少ないと警告されます。ワークフローごとの実行履歴（**履歴を削除…**）、Web サイトのサインイン（**サインインを削除…**）、リプレイキャッシュ（**クリア**）、その他のプロジェクトデータが一覧されます。**デバイス設定 → 実行履歴の保存期間** より古い実行履歴は自動で削除されます。

## ローカルデータの場所

Kitewell は次の場所にデータを保存します。

```text
macOS:    ~/Library/Application Support/Kitewell
Windows:  %LOCALAPPDATA%\Kitewell
```

`data`、`backups`、`runtime`、`logs` の各フォルダーは、それぞれ異なる用途に使われます。データを手動で移動する前に、Kitewell を終了してください。バックアップを残さないまま、インストールの問題を解決する目的でこのディレクトリを削除しないでください。
