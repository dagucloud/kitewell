---
title: バックアップと復旧
---

## バックアップを作成する

**このデバイス → バックアップ**を開き、手動でスナップショットを作成します。アーカイブは、自分で管理できる場所にダウンロードしてください。ローカルバックアップのスケジュールを設定することもできます。バックアップの対象は、デバイス上のすべてのプロジェクトです。

同じデバイス上のバックアップは変更を元に戻すのに役立ちますが、そのデバイス自体を失った場合の備えにはなりません。必要に応じて、保護された別のコピーを保管してください。

## 含まれるもの

スナップショットには、ワークスペースの設定、プロジェクト、ワークフロー定義、インポートした OpenAPI 仕様と API 接続の設定、実行履歴が含まれます。API 接続はシークレットへの参照を保持します。スナップショットには、管理対象のシークレットの値とその復号キー、実行出力のログディレクトリ、ローカルの編集履歴、このデバイスの GUI ログインと API キーのハッシュは含まれません。スナップショットを復元すると、ローカルの編集履歴も消去されます。

アーカイブは暗号化されていません。ワークフロー定義、OpenAPI 仕様、ソース URL に直接入力した認証情報は削除されません。ダウンロードしたスナップショットは機密情報として扱ってください。

[アラート](/ja/docs/alerts/)のチャンネルとルールは含まれますが、それらの送信に使うシークレットは含まれません。メールサーバーのパスワード、Slack と Teams のアドレス、Webhook の URL と署名シークレット、PagerDuty のキーはデバイスに残ります。別のコンピューターで復元した後に、これらを再入力してください。

外部スクリプトとその入力ファイル、Docker ボリューム、マウントしたディレクトリ、サードパーティのサービスは、Kitewell のバックアップにはコピーされません。これらは別途バックアップしてください。クラウドのデバイス認証情報は、ワークスペースのバックアップから除外されます。

## 復元する

実行中の作業を終えてから**このデバイス → バックアップ**を開き、保存済みのスナップショットで**バックアップを復元**を選びます。復元すると安全用のバックアップが作成され、ワークスペースのデータと設定が置き換えられ、ワークスペースが再読み込みされます。このデバイスの GUI ログイン、API キー、停止中のプロジェクトはそのまま保持されます。

管理対象のシークレットは復元されません。ワークフローやプロジェクトのリソースに必要な認証情報を再入力し、対応が必要と報告された項目を確認してください。アーカイブの上限は、展開後のデータで 2 GiB です。

## ローカルデータの場所

macOS では、Kitewell は次の場所にデータを保存します。

```text
~/Library/Application Support/Kitewell
```

`data`、`backups`、`runtime`、`logs` の各フォルダーは、それぞれ異なる用途に使われます。データを手動で移動する前に、Kitewell を終了してください。バックアップを残さないまま、インストールの問題を解決する目的でこのディレクトリを削除しないでください。
