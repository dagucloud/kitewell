---
title: Dagu Cloud でプロジェクトを同期
---

[Dagu Cloud](https://console.dagu.sh) を通じてプロジェクトを同期すると、使っているすべてのデバイスで同じ状態に保ち、チームと共有できます。Dagu Cloud が保持するのはプロジェクトの定義です。ワークフローは引き続き各デバイスが自身の認証情報で実行し、シークレットの値がデバイスの外に出ることはありません。同期は任意です。同期を選ぶまで、プロジェクトはそのデバイス上にとどまります。

## 同期される内容

プロジェクトを同期するまで、Dagu Cloud には何も送信されません。アカウントがなければ、Kitewell が Dagu Cloud に接続することはありません。サインインしていても、デバイスが行うのはプランの確認と Kitewell のバージョンの報告だけで、ワークフロー、設定、実行履歴、ログ、シークレットは送信しません。同期で送信されるのは選んだプロジェクトだけで、そのシークレットの値は決して送信されません。

同期プロジェクトに含まれる内容は、[プロジェクトのエクスポート](/ja/docs/sharing/)と同じです。ワークフロー定義とスケジュール、エージェントとモデル、API 接続とインポートした仕様、サーバーとグループ、キュー、イメージレジストリ、シークレットの名前と説明、バッチシート、プロジェクトのワークフロー既定値が含まれます。さらに、エクスポートには含まれないプロジェクトの[リリース](/ja/docs/releases/)も同期されます。

:::note[シークレットはデバイスに残ります]
シークレットの値が Dagu Cloud に送信されることはありません。同期されたプロジェクトは使うシークレットを名前で示し、値は各デバイスがそれぞれ保存し、そのデバイス上で設定します。設定するまで、**シークレット** には **値が必要** と表示されます。書かれたとおりに送信されるのは、ワークフローの YAML、バッチ入力、API アドレスに直接入力したテキストだけです。認証情報は[シークレット](/ja/docs/secrets/)に保存してください。
:::

レジストリのサインイン、SSH 鍵とホスト鍵、作業ディレクトリ、ワークフローの有効・無効、アラート、実行履歴、ログも、各デバイスがそれぞれ保持します。これらも Dagu Cloud には送信されません。

## サインイン

1. **このデバイス → デバイス設定** を開き、**Dagu Cloud でサインイン** を選びます。
2. ブラウザーで Dagu Cloud が開きます。サインインし、Kitewell に表示されたコードと一致することを確認してから、デバイスを接続します。

デバイスは 1 つのワークスペースと同期し、**デバイス設定** に **ワークスペース** として表示されます。1 人につき、1 つのワークスペースに最大 3 台のデバイスを接続できます。4 台目を接続すると、最も古いデバイスの接続が解除されます。無料アカウントで同期できるプロジェクトは 1 つです。Kitewell Pro では、チームごとに最大 10 個のプロジェクトを、それぞれ最大 200 個のワークフローまで同期できます。プランに空きのないプロジェクトの同期は、理由とともに拒否されます。同期プロジェクトは、デバイスのプロジェクト数の上限ではなく、ワークスペースのプランに数えられます。

## プロジェクトを同期する

1. プロジェクトセレクターを開き、**プロジェクトを管理** を選びます。
2. プロジェクトの横にある **Dagu Cloud に同期** を選び、確認します。

以降、保存はすべてまず Dagu Cloud に送られます。ワークフローの YAML、バッチ入力、API アドレスは書かれたとおりに共有されるため、同期する前に、そこに直接入力したシークレットを削除してください。

別のデバイスでプロジェクトを使うには、そのデバイスでサインインし、**プロジェクトを管理 → Dagu Cloud からダウンロード** を開いて **ダウンロード** を選びます。**Dagu Cloud のプロジェクト** では、すでに **このデバイス上** にあるプロジェクトと、閲覧だけが許可されたプロジェクトが示されます。デバイスにある既存のプロジェクトと同じ名前のプロジェクトは、どちらかの名前を変えるまでダウンロードできません。ダウンロードしたワークフローは一時停止の状態で届きます。そのデバイスで実行するものを有効にしてください。

アップロードが途中で止まると、プロジェクトに **アップロード未完了** と表示されます。**アップロードを再開** を選んでください。アップロードが終わるまで、保存は待たされます。

## 最新の状態に保つ

Kitewell は、起動時、プロジェクトを開いたとき、ワークフローを編集のために開いたときに、ほかの場所で行われた変更を取り込みます。Dagu Cloud への確認は最大で 1 分に 1 回です。それ以外のタイミングで確認するには、**プロジェクトを管理** で **Dagu Cloud から更新** を選びます。エディターで開いているワークフローは、何も入力していなければ、その場で更新を取り込みます。

変更を取り込むと、プロジェクトのエンジンが再起動します。すでに進行中の実行は、開始時の定義のまま続きます。そのデバイスにとって新しいワークフローは一時停止の状態で届きます。すでにあるワークフローは、スケジュールの設定、作業ディレクトリ、アラートをそのまま保持します。

開いた後に誰かが同じ項目を保存していた場合、保存は中断され、**Dagu Cloud で変更されています** と表示されます。相手の変更を自分の変更で置き換えるには **上書き** を、保存せずに編集内容を残すには **キャンセル** を選びます。

同期プロジェクトのファイルは Kitewell が管理します。Kitewell の外でファイルを編集しても、そのファイルへの変更が Dagu Cloud から届いたときや、次に Kitewell で保存したときに置き換えられます。

## 閲覧のみのプロジェクト

あなたの役割が **Viewer** のプロジェクトには、ページのヘッダーとダウンロード一覧に **閲覧のみ** と表示されます。ワークフローの実行、デバイス上でのシークレットの値の設定、このデバイスで実行するワークフローの有効化はできますが、ワークフローの変更、リリースの作成や適用、シークレットの宣言など、Dagu Cloud が拒否する編集は表示されません。

## チームで作業する

チームは Kitewell Pro で同期プロジェクトを共有します。料金は 1 人あたり月額 $25 で、10 人まで利用できます。それより大きなチームは [Enterprise](/ja/pricing/#enterprise) をご利用ください。チームのオーナーがすべてのシートの料金を支払うため、メンバーが個別にサブスクリプションを契約する必要はありません。

オーナーは Dagu Cloud の **Kitewell** ページでチームを管理します。

- **招待** から、メールアドレスで相手を招待します。招待は、承諾されるか、取り消されるか、7 日後に期限切れになるまで、シートを 1 つ確保します。招待された人は、そのメールアドレスで Dagu Cloud にサインインして招待を承諾します。
- **席数** で、サブスクリプションで料金を支払う人数を設定します。
- **同期プロジェクト** には、チームが同期しているすべてのプロジェクトが一覧表示され、プロジェクトごとに各メンバーのロールを設定できます。
  - **閲覧者** は、プロジェクトを閲覧し、ダウンロードできます。
  - **編集者** は、さらに変更を保存できます。
  - **管理者** は、さらに Dagu Cloud からプロジェクトを削除できます。
  - **アクセスなし** では、プロジェクトは表示されません。

オーナーはすべてのプロジェクトを開けます。プロジェクトを同期したメンバーは、そのプロジェクトの管理者になります。

:::caution
編集者が保存した変更は、プロジェクトを同期しているすべてのデバイスで、各デバイスが更新を取り込んだ時点から実行されます。編集者のロールは、チームのデバイス上でコマンドを実行させても問題ないと信頼できる人にだけ付与してください。
:::

メンバーも同じ方法でデバイスを接続し、Dagu Cloud に尋ねられたらチームのワークスペースを選びます。

## 同期を停止する

**プロジェクトを管理** の **同期を停止** を選ぶと、プロジェクトはこのデバイスと Dagu Cloud の両方に残り、以降このデバイスで保存した内容はローカルにとどまります。ダウンロード一覧の **Dagu Cloud から削除** は、あなたの役割が **Admin** の場合に表示され、このデバイスで同期していないプロジェクトを削除し、プランの枠を空けます。ほかのデバイスのコピーは Dagu Cloud に保存できなくなります。別のワークスペースと同期しているプロジェクトには **別のワークスペース** と表示され、**同期を停止** だけを選べます。

プロジェクトが Dagu Cloud から削除された場合や、そのプロジェクトへのアクセス権を失った場合、プロジェクトはローカルプロジェクトとしてデバイスに残ります。

デバイスがオフラインのときは、そのデバイスの同期プロジェクトに保存できません。ワークフローの有効化やシークレットの値の設定など、デバイスにとどまる変更は引き続き行え、有効なワークフローはデバイス上のコピーから実行されます。Dagu Cloud がデバイスの接続を受け付けなくなった場合は、**デバイス設定** の **アカウントを再接続** を使います。
