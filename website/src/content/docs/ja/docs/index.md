title: Kitewell ドキュメント
---

Kitewell は、ワークフローを自分のマシンで実行します。これまで手作業でやっていた仕事を、スケジュールどおりに、すべての実行を記録しながら片付けるためのアプリです。

- **[ワークフローを組み立てる](/ja/docs/workflow-builder/)**：コマンドやスクリプト、コンテナー、SSH、HTTP リクエスト、AI のステップ、人による承認を組み合わせます。
- **[Web サイト](/ja/docs/browser/)**、**[デスクトップアプリ](/ja/docs/desktop/)**、**[メール](/ja/docs/email/)** を、自然な言葉で自動操作します。
- **[Excel を自動化](/ja/docs/spreadsheets/)**：現場にあるブックをそのまま読み、結果を元の行に書き戻します。
- **[シートで一括実行](/ja/docs/batches/)**：行ごとに 1 回ずつ実行し、各実行の結果を集めます。
- **[アシスタントに任せる](/ja/docs/ai/#the-assistant)**：ワークフローの作成と修正を手伝わせ、失敗した実行を[診断](/ja/docs/ai/#failure-diagnosis)させます。
- **[OpenAPI 仕様をインポート](/ja/docs/apis/)**：仕様から生成されたリクエストフォームに入力します。
- **[プロジェクトを共有](/ja/docs/sharing/)**、または **[Dagu Cloud と同期](/ja/docs/cloud-sync/)** して、すべてのコピーを同じ状態に保ちます。各デバイスは独自の認証情報を用意し、そのデバイスで実行すべきワークフローだけを有効にします。

:::note[初期リリースについて]
Kitewell は公開されたばかりのため、機能や制限は今後変更される可能性があります。公開インストーラーは macOS と Windows 向けです。Linux への対応も予定しています。現在のリリース状況は[ダウンロード](/ja/download/)で確認してください。
:::

## どこで何が実行されるか

Kitewell は、プロジェクトごとにローカルの Dagu ワークフローエンジンを実行します。ワークフローは、Kitewell を実行しているユーザーアカウントの権限で実行されます。信頼できるワークフロー定義とコマンドだけを実行してください。

[Dagu Cloud と同期](/ja/docs/cloud-sync/)することを選ばない限り、プロジェクトはデバイス上にとどまります。シークレットの値がデバイスの外に出ることはありません。アシスタントとの会話、失敗の診断、シートに読み取った値もデバイスに残ります。AI の機能は、実行の出力やワークフローの定義など、読み取った内容を選んだモデルのプロバイダーに送信します。送り先の一覧は[コンピューターの外に出るもの](/ja/docs/data-flow/)にあります。

ウィンドウを閉じても、Kitewell は macOS ではメニューバー、Windows ではトレイに残って動き続けます。**Quit Kitewell** を選ぶと、サービスとエンジンが停止します。

スケジュールされた作業を実行するには、コンピューターがスリープしておらず、ユーザーがサインインしている必要があります。Kitewell はホスト型のマシンを提供しません。AI プロバイダー、リモートサーバー、コンテナ、外部サービスには、それぞれ独自の要件と費用があります。
