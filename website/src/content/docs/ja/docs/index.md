---
title: Kitewell ドキュメント
---

Kitewell は、ワークフローを自分のマシンで実行します。スクリプト、AI エージェント、コンテナ、API 呼び出しを組み合わせてスケジュールを設定し、各実行を 1 つの画面で確認できます。[OpenAPI 仕様をインポート](/ja/docs/apis/)すると、API オペレーションを選び、仕様から生成されたリクエストフォームに入力できます。プロジェクトをエクスポートして別のデバイスやチームメイトのためにインポートしたり、[Dagu Cloud と同期](/ja/docs/cloud-sync/)してすべてのコピーを同じ状態に保ったりできます。各デバイスは独自の認証情報を用意し、そのデバイスで実行すべきワークフローだけを有効にします。

:::note[パブリックベータ]
Kitewell はパブリックベータのため、機能や制限は今後変更される可能性があります。最初の公開インストーラーは macOS 向けです。Linux と Windows への対応も予定しています。現在のリリース状況は[ダウンロード](/ja/download/)で確認してください。
:::

最大 10 個のワークフローを持つ 1 つのプロジェクトと 1 つの API キーまでは無料で、Kitewell アカウントも不要です。Pro は 1 人あたり月額 $15 の予定で、それぞれ最大 200 個のワークフローを持つプロジェクトを最大 10 個、無制限の API キー、[アラート](/ja/docs/alerts/)、プロジェクトを同期するチームを利用できます。プロジェクトごとに、ワークフロー、履歴、シークレットは分かれています。

## どこで何が実行されるか

Kitewell は、プロジェクトごとにローカルの Dagu ワークフローエンジンを実行します。ワークフローは、Kitewell を実行しているユーザーアカウントの権限で実行されます。信頼できるワークフロー定義とコマンドだけを実行してください。

[Dagu Cloud と同期](/ja/docs/cloud-sync/)することを選ばない限り、プロジェクトはデバイス上にとどまります。シークレットの値がデバイスの外に出ることはありません。

macOS では、ウィンドウを閉じても Kitewell はメニューバーに残ります。**Quit Kitewell** を選ぶと、サービスとエンジンが停止します。

スケジュールされた作業を実行するには、コンピューターがスリープしておらず、ユーザーがサインインしている必要があります。Kitewell はホスト型のマシンを提供しません。AI プロバイダー、リモートサーバー、コンテナ、外部サービスには、それぞれ独自の要件と費用があります。
