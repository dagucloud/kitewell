---
title: AI エージェントとモデル
---

Kitewell は、ローカルにインストールされた AI コマンドラインツールと、API ベースのモデルを使えます。AI クレジットの提供や、それらのツールへの代理サインインは行いません。

## コマンドラインエージェント

使いたいコマンドラインエージェント（Codex、Claude Code、OpenCode、GitHub Copilot、Gemini、Cursor）をインストールし、サインインします。**エージェントとモデル** で名前付きのエージェントを設定し、ハーネスとモデルを選んで、**エージェントをテスト** でツールがインストールされサインイン済みであることを確認します。

ワークフローに **AI エージェントに頼む** タスクを追加し、エージェントを選んで、プロンプトとコンテキストを入力します。作業フォルダーと権限を確認してください。エージェントは、そのプロセスから利用できるファイルやツールを操作できます。

## API モデル

プロバイダー（Anthropic、OpenAI、Gemini、OpenRouter、Z.ai、またはローカルサーバー）とモデル ID を指定して、名前付きのモデルを設定します。プロバイダーの API キーはプロジェクトの[シークレット](/ja/docs/secrets/)に保存し、そのシークレットをモデルの認証情報として選びます。ローカルのモデルサーバーでは、到達可能なベース URL を指定します。**モデルをテスト** は短いリクエストを送信して設定を確認します。モデルを使うには、**モデルに尋ねる** タスクを追加します。

**判断モデルを追加** では、**AI に判断を依頼** タスクで使う OpenRouter または TypeSafe のモデルを設定します。このタスクは、分類、スコア付け、はい／いいえで答える質問への回答を行い、後続のステップが分岐に使える構造化された回答を返します。

## 実行を確認する

実行する前に、**ツール → AI プロンプトを確認** で作成したプロンプトを確認できます。実行後は **実行とログ** を開き、記録されたプロンプトとタスクの出力を確認します。

AI のプロンプトとコンテキストは、選択したプロバイダーまたはツールに送信されます。プロバイダーの課金、データ保持、プライバシーのルールが適用されます。Kitewell のワークスペースがローカルにあっても、すべてのタスクがオフラインで完結するわけではありません。
